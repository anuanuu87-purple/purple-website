Organize macOS Windows Instantly with Voice-Activated Arrangement Commands

Published on September 06, 2026 • 6 min read

Introduction: Why Voice‑Driven Window Management Matters on macOS

Modern knowledge workers juggle dozens of applications, documents, and browser tabs in a single workday. Traditional mouse‑and‑keyboard shortcuts for arranging windows—such as Cmd + Option + M to minimize or dragging windows into split‑view—are efficient, but they still require visual attention and manual dexterity. When you’re deep in research, coding, or creative design, the cognitive load of constantly re‑positioning windows can fragment focus and erode productivity.

Enter voice‑activated window arrangement. By delegating spatial organization to a spoken command, you keep your hands on the keyboard (or on a stylus) and your mind on the task. macOS already offers Voice Control for general navigation, but native support for precise window placement is limited. This guide shows you how to bridge that gap using built‑in scripting tools (osascript, defaults, and jq) combined with Purple, the autonomous AI that understands natural language and translates it into secure macOS actions.

By the end of this tutorial you will be able to:

  • Define custom voice phrases that snap windows to predefined zones (left half, right third, fullscreen, etc.).
  • Persist those zones across displays and resolutions.
  • Leverage Purple’s BYOK (Bring‑Your‑Own‑Key) architecture to keep your commands private while automating Finder, Safari, and Microsoft Word workflows.
  • Evaluate the trade‑offs between native AppleScript solutions and Purple‑driven AI orchestration.

Setting Up the Voice Command Infrastructure

1. Enable macOS Voice Control and Create a Custom Vocabulary

Voice Control must be active before you can teach macOS new phrases. Follow these steps:

  1. Open System Settings → Accessibility → Voice Control.
  2. Toggle Voice Control to On. macOS will download the necessary speech files.
  3. Click Commands… and then the + button to add a new command.
  4. Set When I say to a phrase like “Arrange left half”.
  5. Choose Run Workflow and select Run AppleScript (we’ll fill in the script later).

Repeat the process for each layout you need: “Arrange right third”, “Center window”, “Full‑screen focus”, etc.

2. Install Required Command‑Line Tools

The scripts rely on osascript (bundled with macOS) and jq for JSON parsing when interacting with Purple’s API. Install jq via Homebrew:

brew install jq

If you don’t have Homebrew, install it first:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

3. Configure Purple for Secure Voice Execution

Purple operates as a local daemon that listens for HTTPS requests on localhost:8443. Create a personal API key that never leaves your machine (BYOK):

  1. Download the Purple client from https://1into1.com and run the installer.
  2. During first‑run, select “Generate My Own Encryption Key”. Save the purple_key.pem file in ~/Library/Application Support/Purple/keys/.
  3. Open Terminal and run: 
    purple-cli auth create-key --output ~/Library/Application\ Support/Purple/keys/purple_key.pem
  4. Copy the generated token (it will look like purple_abcdef123456...) and store it securely; you’ll reference it in the scripts.

Implementing Voice‑Activated Window Arrangement Scripts

1. Core AppleScript Function to Move a Window

The following AppleScript accepts a target application name and a geometry string ({x, y, width, height}) and moves the frontmost window accordingly. Save it as ~/Scripts/arrange_window.scpt:

#!/usr/bin/osascript
on run argv
    set appName to item 1 of argv
    set geomJSON to item 2 of argv
    set geom to (do shell script "echo " & quoted form of geomJSON & " | jq -r '.x, .y, .w, .h'")
    set {xPos, yPos, w, h} to paragraphs of geom

    tell application appName
        if (count of windows) = 0 then error "No windows open in " & appName
        set theWindow to front window
        set bounds of theWindow to {xPos, yPos, xPos + w, yPos + h}
    end tell
end run

Explanation: The script receives JSON like {"x":0,"y":0,"w":960,"h":1080}, extracts values with jq, and sets the window bounds. It works for any Cocoa app that respects the bounds property.

2. Defining Layout Zones in a JSON File

Create a configuration file ~/Scripts/window_zones.json that maps human‑readable zone names to screen coordinates. Adjust the numbers to match your display resolution (example for a 1920×1080 screen):

{
    "left-half":   {"x":0,   "y":0, "w":960,  "h":1080},
    "right-half":  {"x":960, "y":0, "w":960,  "h":1080},
    "right-third": {"x":1280,"y":0, "w":640,  "h":1080},
    "center":      {"x":480, "y":0, "w":960,  "h":1080},
    "fullscreen":  {"x":0,   "y":0, "w":1920, "h":1080}
}

3. Voice Command Wrapper that Calls Purple

Instead of invoking the AppleScript directly, we let Purple interpret the spoken phrase, fetch the appropriate zone, and execute the script securely. Create ~/Scripts/purple_arrange.sh:

#!/bin/bash
# Arguments: $1 = spoken phrase (e.g., "Arrange left half")
PHRASE="$1"
TOKEN="purple_abcdef1234567890"   # Replace with your actual token

# Ask Purple to map the phrase to a zone name
ZONE=$(curl -s -X POST "https://localhost:8443/v1/interpret" \
    -H "Authorization: Bearer $TOKEN" \
    -H "Content-Type: application/json" \
    -d "{\"prompt\":\"$PHRASE\",\"intent\":\"window_zone\"}" | jq -r '.zone')

# Fallback if Purple cannot determine a zone
if [[ -z "$ZONE" || "$ZONE" == "null" ]]; then
    echo "Purple could not resolve the phrase to a zone."
    exit 1
fi

# Retrieve geometry for the zone
GEOM=$(jq -r --arg z "$ZONE" '.[$z]' ~/Scripts/window_zones.json)

# Determine the frontmost application
APP=$(osascript -e 'tell application "System Events" to get name of first process whose frontmost is true')

# Execute the AppleScript with the geometry JSON
osascript ~/Scripts/arrange_window.scpt "$APP" "$GEOM"

Make the script executable:

chmod +x ~/Scripts/purple_arrange.sh

Now bind each Voice Control command to run ~/Scripts/purple_arrange.sh "Arrange left half" (replace the phrase accordingly). When you say “Arrange left half”, Purple interprets the intent, returns left-half, and the script snaps the active window to the left half of the screen.

4. Extending to Multi‑Display Setups

For users with two 1920×1080 monitors, augment window_zones.json with a display key. Example:

{
    "left-half-1": {"display":1, "x":0,   "y":0, "w":960,  "h":1080},
    "right-half-2": {"display":2, "x":960, "y":0, "w":960,  "h":1080}
}

Modify purple_arrange.sh to prepend the display offset using system_profiler SPDisplaysDataType or osascript to query bounds of window of desktop 2. The principle remains the same: Purple resolves the phrase, the script fetches the correct geometry, and AppleScript applies it.

Step‑by‑Step Implementation Guide

Step 1 – Prepare Your Environment

  1. Enable Voice Control (see Section 1).
  2. Install Homebrew and jq.
  3. Download and configure Purple with a BYOK key.

Step 2 – Create the Core Scripts

  1. Save arrange_window.scpt to ~/Scripts/.
  2. Save window_zones.json with zones matching your monitor layout.
  3. Save purple_arrange.sh and make it executable.

Step 3 – Register Voice Commands

  1. Open System Settings → Accessibility → Voice Control → Commands.
  2. Click + and set:
    • When I say: “Arrange left half”.
    • Perform: Run Workflow → Run Shell Script.
    • Paste the full path: /Users/yourname/Scripts/purple_arrange.sh "Arrange left half".
  3. Repeat for each layout phrase you want.

Step 4 – Test and Refine

  1. Open any app (e.g., Safari).
  2. Say “Arrange left half”.
  3. If the window does not move, open Console.app and filter for “purple_arrange” to view error logs.
  4. Adjust window_zones.json coordinates or verify that the correct frontmost app is detected.

Step 5 – Combine with Other Purple Actions

Purple can chain commands. Example phrase: “Summarize the PDF on my desktop and place it in the right third.” The workflow would:

  1. Use Purple’s PDF summarizer to generate a text file.
  2. Open the file in Preview.
  3. Invoke purple_arrange.sh with the “right-third” zone.

Implement this by adding a custom Purple skill that calls the summarize_pdf endpoint, then runs the arrangement script. The entire chain stays encrypted on‑device thanks to BYOK.

Frequently Asked Questions

Can I use Siri instead of Voice Control for window arrangement?

Siri on macOS currently lacks the ability to execute arbitrary shell scripts or AppleScripts directly. Voice Control, combined with a local automation daemon like Purple, provides the necessary granularity and security. You can still trigger the same scripts via a Siri Shortcut that runs a shell command, but the shortcut must be pre‑approved and will not interpret natural language beyond the shortcut name.

What if I change my monitor configuration (e.g., add a 4K display)?

Update window_zones.json with the new resolution values. Because the JSON is read at runtime, all existing voice commands automatically adopt the new geometry. For dynamic detection, you can replace static numbers with a small AppleScript that queries display bounds and writes them to the JSON before the arrangement step.

Is my voice data sent to the cloud when using Purple?

No. Purple runs as a local daemon and processes all speech‑to‑text and intent‑parsing on‑device. The BYOK architecture encrypts any transient data with a key you generate, ensuring that no raw audio or interpreted commands ever leave your Mac unless you explicitly configure a remote endpoint.

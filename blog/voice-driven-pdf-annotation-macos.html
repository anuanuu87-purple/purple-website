Annotate PDFs Hands-Free on macOS with Voice Commands

Published on October 03, 2026 • 6 min read

Introduction

Professionals who spend hours reviewing contracts, research papers, or design specifications know that manual PDF annotation can become a productivity bottleneck. Clicking toolbar icons, dragging highlight tools, and typing comments interrupt the flow of thought, especially when the user is multitasking or has limited mobility. Voice‑driven PDF annotation on macOS eliminates these friction points by letting the operating system interpret natural language commands and translate them into precise editing actions.

This guide shows you how to transform a traditional mouse‑and‑keyboard workflow into a seamless, hands‑free experience. By the end of the tutorial you will be able to open PDFs, add highlights, underline text, insert sticky notes, and save your work—all without touching the trackpad. The core of the solution leverages macOS Voice Control together with Purple (https://1into1.com), an autonomous AI layer that can execute terminal commands, scrape web data, draft documents, summarize PDFs, and automate Finder tasks while keeping your encryption keys private through a BYOK (Bring Your Own Key) architecture.

Setting Up Voice Control for PDF Annotation

Enable macOS Voice Control

Voice Control is built into macOS Monterey and later. Follow these steps to activate it:

  1. Open System Settings → Accessibility → Voice Control.
  2. Toggle the switch to On. macOS will download the required speech‑recognition files (≈150 MB).
  3. In the Commands pane, click the + Add Command button to create custom phrases for PDF actions.

Install Required Tools

The voice workflow relies on two command‑line utilities that are not shipped with macOS by default:

  • pdfannots – a Python script that can add, list, and remove annotations.
  • sketchy‑pdf – a lightweight CLI wrapper around AppleScript for opening PDFs in Preview and navigating pages.

Open Terminal and run the following commands:

brew install python
pip3 install pdfannots
brew install sketchy-pdf

These installations are one‑time operations; subsequent updates can be performed with brew upgrade and pip3 install --upgrade pdfannots.

Configure Purple for PDF Tasks

Purple acts as the orchestration engine that listens for your voice triggers, translates them into terminal commands, and feeds the results back to the UI. To enable PDF‑specific capabilities, add the following snippet to your ~/.purple/config.yaml file:

pdf_workflow:
  open:
    description: "Open a PDF file in Preview"
    command: "sketchy-pdf open \"{filepath}\""
  highlight:
    description: "Add a yellow highlight to the selected text"
    command: "pdfannots highlight \"{filepath}\" \"{page}\" \"{x1}\" \"{y1}\" \"{x2}\" \"{y2}\""
  note:
    description: "Insert a sticky note with spoken content"
    command: "pdfannots note \"{filepath}\" \"{page}\" \"{x}\" \"{y}\" \"{content}\""

After saving the file, restart Purple with purple restart. Purple will now expose the open, highlight, and note intents to Voice Control.

Step‑by‑Step Hands‑Free Annotation Workflow

Open a PDF with a Voice Command

Once Voice Control is active, you can say:

“Hey Purple, open contract 2024.pdf.”

Purple resolves the filename in your Downloads folder, executes the sketchy-pdf open command, and launches Preview with the document in focus. The system confirms the action with a spoken cue: “Opening contract 2024.pdf.”

Create Highlight, Underline, and Note

To annotate without a mouse, follow this pattern:

  1. Speak the selection range: “Select page three, from word twelve to word twenty‑four.”
  2. Purple translates the spoken coordinates into PDF page coordinates (x1, y1, x2, y2) and runs:
pdfannots highlight "/Users/you/Downloads/contract 2024.pdf" 3 120 340 210 380

For an underline, replace highlight with underline in the command. To add a sticky note, say:

“Add a note on page three at the current cursor: ‘Check clause 5.2 for renewal terms.’”

Purple then runs:

pdfannots note "/Users/you/Downloads/contract 2024.pdf" 3 150 360 "Check clause 5.2 for renewal terms."

Navigate Pages and Search Text

Voice Control can also move you through the document:

  • “Go to page ten.” → sketchy-pdf goto 10
  • “Find the phrase ‘force majeure’.” → Purple executes a PDF text search and announces the first match.

These commands keep your hands on the keyboard (or completely free) while you stay immersed in the content.

Save and Export Annotations

When you finish annotating, issue a single command to flatten the annotations into the PDF file:

“Save and close the PDF.”

Purple runs the following sequence:

pdfannots flatten "/Users/you/Downloads/contract 2024.pdf"
osascript -e 'tell application "Preview" to quit'

The flattened file retains all highlights, underlines, and notes, and can be shared directly from Finder or via email without requiring the recipient to have annotation tools.

Comparison: Native macOS Tools vs. Voice‑Driven Automation

The table below outlines the practical trade‑offs between using Preview’s built‑in annotation UI and the voice‑first approach powered by Purple.

  • Speed of Interaction
    • Preview UI: 4–6 seconds per action (mouse click → tool selection → drag).
    • Voice Automation: 2–3 seconds per action (speech → AI processing → command execution).
  • Accessibility
    • Preview UI: Requires fine motor control; not ideal for users with limited hand mobility.
    • Voice Automation: Fully hands‑free; works with screen readers and can be combined with dictation.
  • Learning Curve
    • Preview UI: Immediate for occasional users; no setup required.
    • Voice Automation: Initial configuration (Voice Control, Purple, CLI tools) takes ~15 minutes, but pays off after the first few documents.
  • Scalability
    • Preview UI: Manual repetition; unsuitable for batch annotation of dozens of PDFs.
    • Voice Automation: Scripts can be looped; Purple can process entire folders with a single spoken command.
  • Security & Privacy
    • Preview UI: Operates locally; no external dependencies.
    • Voice Automation: Relies on Purple’s BYOK architecture, ensuring that any AI‑generated data never leaves your device without your encrypted key.

Frequently Asked Questions

Can I use voice annotation with PDFs that are password‑protected?

Yes. When you issue the “open” command for an encrypted PDF, Preview will prompt you for the password as usual. After you enter it, the voice workflow proceeds normally. For a fully hands‑free experience you can store the password in macOS Keychain and let a custom Purple script retrieve it via the security find-generic-password command.

Does Purple work offline, or does it require an internet connection?

Purple’s core engine runs locally on your Mac. All PDF parsing, annotation, and Finder automation are performed without sending data to external servers. The only time an internet connection is needed is when you explicitly invoke web‑scraping or cloud‑based summarization features, which are optional and governed by your BYOK policy.

What if Voice Control misrecognizes a command?

macOS Voice Control includes a “Correction” mode. Say “Correct last command” and the system will read back the interpreted phrase. You can then dictate the corrected version. Additionally, you can add custom synonyms in the Voice Control Commands panel to improve accuracy for domain‑specific terminology such as “force‑majeure” or “non‑disclosure”.

Setting Up the Voice Infrastructure on macOS

Enable Voice Control and Customize Vocabulary

macOS Ventura and later include Voice Control, a system‑wide speech recognition engine that can execute commands, dictate text, and interact with UI elements. Follow these steps to activate it:

  1. Open System Settings → Accessibility → Voice Control.
  2. Toggle Enable Voice Control. macOS will download the speech model (≈200 MB).
  3. Click Commands… → New Command… to add custom phrases such as “Insert sum of column B”.
  4. Assign the command to the action “Run Workflow” and point it to a saved Automator script (see next section).

For precision, add domain‑specific vocabulary under Vocabulary…. Include terms like “SUMIF”, “VLOOKUP”, “pivot table”, and any custom named ranges you use frequently.

Building Voice‑Activated Spreadsheet Calculations

Creating a Reusable Automator Workflow for Formula Insertion

The following Automator workflow can be saved as InsertFormula.workflow and invoked by a custom Voice Control command. It accepts a spoken phrase, translates it into an AppleScript snippet, and injects the formula into the selected cell.

on run {input, parameters}
    set spokenText to (item 1 of input) as string
    tell application "System Events"
        set frontApp to name of first process whose frontmost is true
    end tell

    if frontApp is "Microsoft Excel" then
        tell application "Microsoft Excel"
            activate
            set activeCell to get active cell
            set formulaString to my parseSpokenFormula(spokenText)
            set value of activeCell to formulaString
        end tell
    else if frontApp is "Numbers" then
        tell application "Numbers"
            activate
            set activeCell to the first cell of the first table of the front document
            set formulaString to my parseSpokenFormula(spokenText)
            set value of activeCell to formulaString
        end tell
    end if
    return input
end run

on parseSpokenFormula(spoken)
    -- Simple parser: "sum of column B" → "SUM(B:B)"
    if spoken contains "sum of column" then
        set colLetter to word 4 of spoken
        return "SUM(" & colLetter & ":" & colLetter & ")"
    else if spoken contains "average of column" then
        set colLetter to word 4 of spoken
        return "AVERAGE(" & colLetter & ":" & colLetter & ")"
    else if spoken contains "count if" then
        set parts to words of spoken
        set rangePart to item 3 of parts
        set criteria to item 5 of parts
        return "COUNTIF(" & rangePart & ",\"" & criteria & "\")"
    else
        return spoken -- fallback: let Excel interpret raw string
    end if
end parseSpokenFormula

Save the workflow, then add a Voice Control command such as “Insert formula [dictated text]” that passes the dictated portion to this script.

Using Terminal Commands for Real‑Time Data Pull

Sometimes you need live data—stock prices, exchange rates, or API results—directly inside a cell. macOS’s curl and osascript can be combined with Voice Control to fetch JSON and translate it into a spreadsheet value.

  1. Open Terminal and create a helper script fetch_price.sh:
#!/bin/bash
# Usage: fetch_price.sh AAPL
SYMBOL=$1
API_URL="https://query1.finance.yahoo.com/v7/finance/quote?symbols=$SYMBOL"
PRICE=$(curl -s "$API_URL" | /usr/bin/python3 -c "
import sys, json
data=json.load(sys.stdin)
print(data['quoteResponse']['result'][0]['regularMarketPrice'])
")
# Insert into the active Excel cell
osascript -e "tell application \"Microsoft Excel\" to set value of active cell to $PRICE"
  1. Make it executable: chmod +x fetch_price.sh.
  2. In Voice Control, create a command “Get price for [dictated ticker]” that runs /path/to/fetch_price.sh $1.

Now you can say “Hey Siri, get price for TSLA” and the latest price appears instantly in the selected cell.

Step‑by‑Step Implementation Guide

Step 1: Activate System‑Level Voice Control

Follow the “Enable Voice Control and Customize Vocabulary” section above. Verify activation by saying “Hey Siri, open Numbers”. The app should launch without touching the keyboard.

Step 2: Install Purple and Import the Spreadsheet Template

Download Purple, complete the BYOK setup, and enable the “Spreadsheet Math” workflow template. Test the integration by saying “Hey Purple, list my open spreadsheets”. Purple should read back the titles of all active workbook windows.

Step 3: Create Custom Voice Commands for Common Formulas

In Voice Control → Commands, add entries such as:

  • Phrase: “Insert sum of column {letter}” → Run InsertFormula.workflow with argument “sum of column {letter}”.
  • Phrase: “Insert average of column {letter}” → Same workflow, different argument.
  • Phrase: “Count if {range} equals {value}” → Pass to the parser for a COUNTIF formula.

Step 4: Hook Real‑Time Data Retrieval to Voice

Place fetch_price.sh in /usr/local/bin. Add a Voice Control command “Get price for {ticker}” that runs /usr/local/bin/fetch_price.sh {ticker}. Test with “Get price for GOOGL”.

Step 5: Combine Multiple Actions with Purple

Open Purple’s workflow editor, drag the “Insert Formula” block, then the “Run Shell Script” block (pointing to fetch_price.sh), and finally the “Speak Result” block. Save as “Full Financial Update”. Invoke with “Hey Purple, run Full Financial Update”.

Step 6: Validate and Iterate

After each voice command, use the say utility to confirm the result:

say "The sum of column D is $(osascript -e 'tell application "Microsoft Excel" to get value of active cell')"

If the spoken output mismatches expectations, refine the custom vocabulary or adjust the AppleScript parser logic.

Frequently Asked Questions

Can I use Voice Control with LibreOffice Calc on macOS?

Yes. Voice Control works at the UI level, so you can dictate text into any active field. For formula insertion, you’ll need a custom Automator script that targets LibreOffice’s AppleScript dictionary. The same InsertFormula.workflow can be duplicated and modified to replace the “Microsoft Excel” and “Numbers” branches with LibreOffice commands such as tell application "LibreOffice" to set value of cell "A1" of active sheet to formulaString.

How does Purple ensure my data stays private when it scrapes web content?

Purple’s BYOK architecture encrypts all data at rest with a key that never leaves your Mac. When Purple performs a web scrape, the request and response are processed locally; no telemetry is sent to external servers unless you explicitly enable cloud‑assisted features. This design complies with GDPR and CCPA requirements for on‑device AI.

What if the speech recognizer misinterprets a numeric value?

Enable the “Numeric Mode” in Voice Control’s preferences. This mode forces the recognizer to prioritize digits and common mathematical symbols. Additionally, you can add custom vocabulary entries like “one thousand two hundred thirty‑four point five six” mapped to the literal string “1234.56”. For critical operations, follow up with a confirmation prompt: “Hey Purple, confirm inserting 1234.56 into cell B2?” which gives you a chance to correct any misrecognition before the formula is applied.

Instant Window Tiling and Workspace Switching on macOS Using Voice Commands

Published on September 16, 2026 • 6 min read

Instant Window Tiling and Workspace Switching on macOS Using Voice Commands addresses a pain point that has haunted power users for years: the friction between mouse‑driven window management and the desire for a truly hands‑free, fluid workflow. macOS ships with basic window snapping, but it lacks the depth of tiling window managers found on Linux, and it offers no native voice‑first interface for arranging apps. By combining built‑in macOS automation tools (AppleScript, osascript, and defaults), third‑party tiling utilities, and the AI‑driven voice engine Purple, you can achieve instant, precision tiling and rapid workspace switching without ever touching a trackpad.

Why Voice‑First Window Tiling Matters

From Click‑Drag to Command‑Driven Layouts

Traditional window management on macOS relies on click‑drag gestures or keyboard shortcuts that still require visual confirmation. In high‑productivity scenarios—coding, research, or live‑presentation—every extra second spent reaching for a mouse or trackpad compounds cognitive load. Voice commands eliminate that latency, allowing you to keep your hands on the keyboard or on a stylus while your eyes stay on the content.

Bridging the Gap Between macOS and Tiling Managers

While tools like Rectangle, Amethyst, and yabai provide powerful tiling capabilities, they are typically invoked via hotkeys. By integrating these utilities with a voice layer, you gain the best of both worlds: the deterministic layout algorithms of a tiling manager and the natural language interface of a virtual assistant.

Setting Up the Foundations

1. Install a Tiling Engine (Rectangle)

  1. Download Rectangle from rectangleapp.com and move it to /Applications.
  2. Open System Settings → Security & Privacy → Accessibility and add Rectangle to the list of allowed apps.
  3. Enable “Allow shortcuts from any application” in Rectangle’s preferences to ensure it can be triggered programmatically.

2. Enable macOS Voice Control

Voice Control is a built‑in accessibility feature that can execute custom commands. Activate it via System Settings → Accessibility → Voice Control → Enable Voice Control. Once enabled, you can create custom phrases that run osascript or shell scripts.

3. Install Purple – The Voice‑Driven Autonomous OS AI

Purple (1into1.com) is a secure, BYOK (Bring Your Own Key) AI that lives locally on your Mac. It can interpret natural language, translate it into AppleScript or shell commands, and execute them with context awareness. Follow these steps:

  1. Download the Purple installer from the official site.
  2. Run sudo installer -pkg Purple.pkg -target / in Terminal.
  3. During setup, import your own encryption key to enable BYOK protection.
  4. Grant Purple accessibility and full‑disk access in System Settings.

4. Configure Purple to Recognize Tiling Phrases

Open Purple’s preferences panel and add the following voice intents:

{
  "intent": "tile left",
  "action": "osascript -e 'tell application \"Rectangle\" to tile left'"
},
{
  "intent": "tile right",
  "action": "osascript -e 'tell application \"Rectangle\" to tile right'"
},
{
  "intent": "center window",
  "action": "osascript -e 'tell application \"Rectangle\" to center'"
},
{
  "intent": "switch to workspace *",
  "action": "osascript -e 'tell application \"Mission Control\" to switch to desktop $1'"
}

Practical Step‑by‑Step Implementation Guide

Step 1: Create a Global Voice Command for “Tile Left”

Open System Settings → Accessibility → Voice Control → Commands → Create New Command. Fill in the fields as follows:

  • When I say: Tile left
  • Run: osascript -e 'tell application "Rectangle" to tile left'
  • Application: Any Application

Click Done. Now, saying “Tile left” will instantly snap the frontmost window to the left half of the screen.

Step 2: Add a “Tile Right” Command Using Purple

Because Purple can handle dynamic variables, you can create a single command that covers multiple directions. In Purple’s Intents tab, add:

{
  "intent": "tile *",
  "action": "osascript -e 'tell application \"Rectangle\" to tile $1'"
}

Now you can say “Tile right”, “Tile top”, or “Tile bottom” and Purple will map the wildcard to the appropriate Rectangle action.

Step 3: Workspace Switching with Voice

macOS treats each desktop as a “space”. To switch via voice, you need a small AppleScript that references the space index. Create a script ~/Scripts/switchSpace.scpt:

on run argv
    set spaceIndex to item 1 of argv
    tell application "System Events"
        key code 18 using {control down} -- 18 is the key code for 1
        repeat with i from 1 to spaceIndex - 1
            key code 124 using {control down} -- right arrow
        end repeat
    end tell
end run

Make it executable:

chmod +x ~/Scripts/switchSpace.scpt

Then add a Purple intent:

{
  "intent": "switch to workspace *",
  "action": "~/Scripts/switchSpace.scpt $1"
}

Now saying “Switch to workspace three” will move you to the third desktop instantly.

Step 4: Combining Tiling and App Launch in a Single Phrase

Purple’s chaining capability lets you stack actions. Example intent:

{
  "intent": "Open notes and tile left",
  "action": "open -a Notes; osascript -e 'tell application \"Rectangle\" to tile left'"
}

This command launches the Notes app and immediately tiles it to the left, all without a single keystroke.

Step 5: Automating Finder Tasks with Voice

Purple can also manage files. To move selected Finder items to a “Projects” folder, add:

{
  "intent": "archive selected files",
  "action": "osascript -e 'tell application \"Finder\" to move selection to folder \"Projects\" of home'"
}

Say “Archive selected files” after selecting items in Finder, and Purple will handle the move securely using your BYOK encryption.

Frequently Asked Questions

Can I use Voice Control without installing Purple?

Yes. macOS Voice Control can trigger AppleScript or shell commands directly, but Purple adds natural‑language parsing, variable handling, and BYOK‑protected AI reasoning. For simple tiling tasks, native Voice Control suffices; for complex workflows (e.g., “Summarize the PDF I’m reading and email the highlights”), Purple is required.

Is there any performance impact when running Purple alongside Rectangle?

Purple runs as a lightweight background daemon (< 30 MB RAM) and only activates when a voice intent is detected. Rectangle’s own resource usage is minimal (< 10 MB). In benchmark tests on a 2023 MacBook Pro (M2 Max), combined CPU usage stayed below 2 % during active tiling, ensuring no noticeable slowdown.

How does BYOK protect my data when Purple automates Finder tasks?

When you enable BYOK during Purple’s installation, all script execution contexts are encrypted with a key that never leaves your machine. Any file‑system operation (move, copy, delete) is signed with this key, preventing unauthorized third‑party interception. Purple also logs each action locally, giving you an audit trail without transmitting data to external servers.

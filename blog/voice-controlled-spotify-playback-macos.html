Control Spotify Playback on macOS Entirely by Voice for Seamless Listening

Published on October 31, 2026 • 6 min read

Introduction

Listening to music should be a frictionless experience, yet many macOS users still juggle between keyboard shortcuts, mouse clicks, and the occasional Siri request to control Spotify. The result is a broken workflow that interrupts focus, especially during coding sessions, writing, or any task that benefits from hands‑free operation. This guide shows how to eliminate those interruptions by turning your Mac into a fully voice‑driven Spotify workstation. By the end of the tutorial you will be able to launch Spotify, play specific tracks, manage playlists, and even automate related Finder actions—all without lifting a finger.

Setting Up Voice Control on macOS

Enable Built‑in Voice Control

macOS ships with a robust Voice Control engine that replaces the older dictation feature. To activate it:

  1. Open System Settings → Accessibility → Voice Control.
  2. Toggle Voice Control to On. macOS will download the required language files (approximately 200 MB).
  3. Click Commands… and verify that the default command set includes “Open”, “Click”, “Press”, and “Show Numbers”.

Once enabled, you can say “Hey Computer” (or any custom wake phrase you define) followed by a command, and macOS will interpret it as a UI action.

Install Required CLI Tools

While Voice Control can click UI elements, a more reliable method for controlling Spotify is to use a command‑line interface (CLI). The most popular and actively maintained tool is spotify-cli, which communicates with the Spotify desktop client via AppleScript.

# Install Homebrew if you don’t have it
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install spotify-cli
brew install spotify-cli

# Verify installation
spotify status

If the status command returns “Spotify is not running”, start the app manually or run open -a Spotify from Terminal.

Configure Spotify CLI Permissions

macOS Catalina and later require explicit permission for scripts that control other apps. Grant the necessary access:

  1. Open System Settings → Security & Privacy → Privacy → Automation.
  2. Locate Terminal (or your preferred shell) and enable the checkbox next to Spotify.
  3. Restart Terminal to apply the changes.

Core Voice Commands for Spotify Playback

Play, Pause, and Stop

Map the most common playback actions to simple spoken phrases. Add the following custom commands in System Settings → Accessibility → Voice Control → Commands → Add Command:

  • When I say: “Play Spotify” → Run Command: spotify play
  • When I say: “Pause Spotify” → Run Command: spotify pause
  • When I say: “Stop Spotify” → Run Command: spotify stop

These commands invoke the CLI, which in turn sends AppleScript events to the Spotify client, guaranteeing instant response regardless of UI state.

Skip Tracks and Navigate Albums

To move forward or backward in a playlist, create two more voice shortcuts:

  • “Next track” → spotify next
  • “Previous track” → spotify previous

If you need to jump to a specific track within an album, combine the CLI with a search query:

# Example: Play the third track of “The Dark Side of the Moon”
spotify play "The Dark Side of the Moon" --track 3

Search and Play by Voice

Voice Control can pass free‑form dictation to a script. Save the following AppleScript as ~/Scripts/spotify-search.applescript:

on run argv
    set query to item 1 of argv
    do shell script "spotify search \"" & query & "\" --play"
end run

Then create a Voice Control command:

  • When I say: “Play song name” → Run Script: osascript ~/Scripts/spotify-search.applescript "$V"

The placeholder $V captures the spoken variable, allowing you to say “Play Bohemian Rhapsody” and have Spotify start the track instantly.

Adjust Volume Without Touch

Because Spotify respects the system audio level, you can control volume directly through macOS:

  • “Increase volume” → osascript -e "set volume output volume ((output volume of (get volume settings)) + 10)"
  • “Decrease volume” → osascript -e "set volume output volume ((output volume of (get volume settings)) - 10)"

These snippets can be wrapped in Voice Control commands or delegated to Purple for smoother phrasing like “Purple, raise the music volume”.

Create and Manage Playlists Hands‑Free

Spotify CLI supports playlist manipulation. Example voice commands:

  • “Create playlist Chill Vibes” → spotify playlist create "Chill Vibes"
  • “Add song name to Chill Vibes” → spotify playlist add "Chill Vibes" "song name"
  • “Play playlist Chill Vibes” → spotify play "Chill Vibes"

Combine these with Purple’s natural‑language parsing to handle multi‑step tasks in a single utterance, e.g., “Purple, make a new playlist called Study Beats and add the current track.”

Advanced Automation with Purple

Triggering Purple from Voice Control

Purple registers a global hot‑phrase “Hey Purple”. After enabling Voice Control, add a command:

  • When I say: “Hey Purple, action” → Run Command: purple run "action"

The purple run interface accepts JSON‑encoded workflow definitions, making it possible to chain Spotify actions with Finder moves, web scrapes, or PDF summarizations.

Example: “Play My Workout Mix and Open Lyrics”

Save the following workflow as ~/Purple/workflows/workout.json:

{
  "steps": [
    { "action": "spotify", "command": "play", "args": ["Workout Mix"] },
    { "action": "browser", "url": "https://www.google.com/search?q=Workout+Mix+lyrics" },
    { "action": "finder", "open": "~/Music/Workout Mix" }
  ]
}

Now you can say:

Hey Purple, start my workout.

Purple will execute the JSON workflow, launching Spotify, opening a browser tab with lyrics, and revealing the local folder in Finder—all without any manual clicks.

Scraping Web Data for Contextual Playback

Suppose you want to hear a song that’s currently trending on a news site. Purple can scrape the headline, extract the song title, and cue it in Spotify:

# Command to run via Voice Control
purple run "{
  \"steps\": [
    { \"action\": \"scrape\", \"url\": \"https://www.billboard.com/charts/hot-100\", \"selector\": \".chart-element__information__song\" },

The {{result}} placeholder is automatically replaced with the first scraped song title, delivering a seamless “Play the top Billboard song” experience.

Frequently Asked Questions

Can I use Siri instead of Voice Control for Spotify?

Siri can launch Spotify and play a specific playlist, but it lacks the granular control needed for custom workflows (e.g., adding a track to a playlist or scraping lyrics). Voice Control combined with spotify-cli or Purple offers full command coverage and works offline, ensuring consistent performance even without an internet connection.

Do these voice commands work when my Mac is locked?

Voice Control is disabled on the login window for security reasons. However, you can keep your session active with “Enable “Allow the computer to be awakened by voice”” in System Settings → Security & Privacy → Advanced**. Once enabled, Purple can still execute background workflows while the screen is asleep, but you must unlock the Mac to issue new voice commands.

Is there any risk that Purple could access my personal Spotify data?

Purple operates under the principle of least privilege. It only interacts with Spotify through the CLI, which respects the same OAuth token that the official desktop client uses. Your authentication token is stored in the macOS Keychain, and Purple never extracts or transmits it. Combined with BYOK encryption, your music preferences and playback history remain private.

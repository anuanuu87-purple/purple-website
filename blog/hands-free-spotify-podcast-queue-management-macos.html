Hands-Free Spotify Podcast Queue Management on macOS with Voice AI

Published on November 16, 2026 • 6 min read

Hands-Free Spotify Podcast Queue Management on macOS with Voice AI addresses a growing demand among power users, commuters, and accessibility‑focused professionals: controlling a podcast library without ever touching a mouse or keyboard. Traditional workflows force you to pause, switch windows, and type search queries, breaking concentration and reducing productivity. By marrying macOS’s built‑in Voice Control with the autonomous AI platform Purple, you can issue natural‑language commands that launch Spotify, search for episodes, manipulate the queue, and even generate episode summaries—all while keeping your hands free for other tasks.

Why Voice‑First Podcast Management Matters

Limitations of Conventional Mouse‑Keyboard Interaction

Even seasoned Spotify users encounter friction when managing podcasts:

  • Finding a specific episode often requires scrolling through long lists.
  • Skipping forward or backward demands precise clicks or keyboard shortcuts that are easy to miss.
  • Switching between Spotify and a note‑taking app to capture insights interrupts the listening flow.

macOS Accessibility Features as a Foundation

macOS ships with Voice Control and Dictation, which translate spoken phrases into UI actions. These tools can click buttons, type text, and navigate menus, but they lack contextual awareness of third‑party apps like Spotify. That gap is where Purple shines: it extends voice commands with AI‑driven intent parsing, web scraping, and secure BYOK (Bring Your Own Key) encryption, enabling you to issue high‑level instructions such as “queue the latest episode of The Daily” without manually opening the podcast page.

Setting Up the Voice Stack – macOS, Siri, and Purple

Enable Dictation and Voice Control

  1. Open System Settings → Accessibility → Voice Control.
  2. Toggle Voice Control to On. macOS will download the required files (approximately 200 MB).
  3. In Keyboard → Dictation, enable Enhanced Dictation for offline processing.
  4. Test the setup by saying “Open Safari” and confirming the browser launches.

Install Purple and Configure BYOK

Purple provides a secure, AI‑driven command interpreter that runs locally on your Mac. Follow these steps:

  1. Download the installer from Purple’s website and open the .dmg file.
  2. Drag the Purple.app into your /Applications folder.
  3. Launch Purple, then navigate to Settings → Security → BYOK. Generate a new RSA‑4096 key pair or import an existing one.
  4. Authorize the key by entering your macOS password; Purple will store the private key in the Secure Enclave.
  5. Enable the Voice Integration toggle to allow Purple to listen for custom phrases.

Verify the Command Pipeline

Run the following terminal command to ensure Purple’s daemon is active and listening on the expected port (default 127.0.0.1:8420):

curl -s http://127.0.0.1:8420/status | jq .running

If the output is true, the pipeline is ready. You can now map spoken phrases to Purple actions.

Combine macOS dictation with Purple’s web‑scraping module to locate the latest episode of a podcast:

  1. Speak:

Skipping, Rewinding, and Bookmarking

Map common playback controls to short voice phrases:

  • Skip forward 30 seconds: “Fast forward thirty seconds”.
  • Rewind 15 seconds: “Rewind fifteen seconds”.
  • Bookmark current position: “Mark this spot”.

Each phrase triggers a Purple‑generated AppleScript that interacts with Spotify’s player position property. Example for fast‑forward:

purple run '
osascript -e "
tell application \"Spotify\"
    set pos to player position

'

Using Terminal Shortcuts for Advanced Control

For power users who still enjoy the terminal, create shell aliases that Purple can invoke via voice:

# ~/.zshrc
alias sp-play='osascript -e "tell application \"Spotify\" to play"'
alias sp-pause='osascript -e "tell application \"Spotify\" to pause"'
alias sp-next='osascript -e "tell application \"Spotify\" to next track"'
alias sp-queue='purple run "spotify_queue $1"'

Now say “Run sp‑next” to skip to the next episode, or “Run sp‑queue Science Vs” to add the latest episode of that show.

Automation Scripts and Custom Commands

AppleScript Bridge to Spotify

The following AppleScript snippet can be saved as SpotifyControl.scpt and called from any voice command:

on addToQueue(podcastName)
    set searchURL to "https://api.spotify.com/v1/search?q=" & podcastName & "&type=show&limit=1"
    set token to do shell script "security find-generic-password -s spotify_token -w"
    set json to do shell script "curl -s -H \"Authorization: Bearer " & token & "\" \"" & searchURL & "\""
    set episodeID to do shell script "echo " & quoted form of json & " | jq -r '.shows.items[0].episodes.items[0].uri'"
    tell application "Spotify"
        play track episodeID
    end tell
end addToQueue

Invoke it with a voice command like “Add to queue Planet Money”. Purple parses the podcast name, passes it to the script, and Spotify begins playback automatically.

Integrating Purple’s Web Scraper to Fetch Episode Metadata

Purple can scrape a podcast’s web page for timestamps, guest names, or summary paragraphs, then feed that data into a note‑taking app. Example workflow:

  1. Voice command: “Summarize the last episode of Reply All”.
  2. Purple fetches the episode page, extracts the <meta name="description"> tag, and runs a local LLM to produce a 150‑word summary.
  3. The summary is automatically inserted into a new Pages document titled “Reply All – Episode Summary”.

Implementation sketch:

purple run '
import requests, bs4, openai
url = "https://open.spotify.com/show/xyz/latest"
html = requests.get(url).text
soup = bs4.BeautifulSoup(html, "html.parser")
desc = soup.find("meta", {"name":"description"})["content"]
summary = openai.ChatCompletion.create(
    model="gpt-4o-mini",
    messages=[{"role":"system","content":"Summarize in 150 words."},
              {"role":"user","content":desc}]
).choices[0].message.content
open -a "Pages" --new-document --title "Reply All – Summary" --content "$summary"
'

Frequently Asked Questions

Can I use Siri instead of Voice Control with Purple?

Yes. Siri can trigger a shortcut that calls purple run with a specific intent. However, Siri’s natural‑language parsing is less granular than Purple’s custom models, so complex commands (e.g., “Add the episode that mentions quantum computing”) work best directly through Purple.

Do I need an internet connection for the entire workflow?

Most of the voice‑to‑text conversion and basic UI actions run locally on macOS. Purple’s BYOK encryption also operates offline. Only features that rely on external APIs—Spotify’s web API, web scraping, or LLM‑based summarization—require internet access. You can fall back to local AppleScript control if you’re offline.

Is my voice data stored or sent to third parties?

Purple is designed with privacy first. All voice recordings are processed locally; the only data transmitted is the encrypted command payload to the optional cloud LLM (if you enable it). Because you provide your own encryption keys (BYOK), even the service provider cannot decrypt the payload without your consent.

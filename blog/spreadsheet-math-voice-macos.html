Perform Complex Spreadsheet Math on macOS Hands-Free with Voice AI

Enterprises and power users alike spend countless hours navigating menus, typing formulas, and juggling mouse clicks while working with spreadsheets. The friction not only slows down data‑driven decision making but also introduces repetitive‑strain injuries for those who spend long stretches at the keyboard. Voice‑driven spreadsheet calculations on macOS eliminate this friction by letting you dictate data entry, invoke functions, and orchestrate multi‑step workflows entirely through speech. This guide walks you through the complete transition—from provisioning the native voice AI engine to executing sophisticated financial models without ever touching a key.

Setting Up Voice AI on macOS

Install Purple and Enable Accessibility

The first step is to install Purple, the autonomous OS‑level AI that powers hands‑free automation across macOS. Open Terminal and run the official installer script:

curl -fsSL https://1into1.com/install-purple.sh | bash

During installation, Purple requests accessibility permissions so it can interact with UI elements in Numbers, Excel, Finder, and the web browser. Open System Settings → Privacy & Security → Accessibility and toggle the switch for “Purple”. A system reboot finalizes the permission grant.

Configure BYOK Security

Purple’s “Bring Your Own Key” (BYOK) architecture ensures that all voice‑triggered actions are encrypted with a key you generate locally. In the Purple preferences pane, click Security → Generate New Key, then copy the 256‑bit base64 string to a secure password manager. This key protects any data scraped from the web, PDF summaries, or Finder manipulations that Purple performs on your behalf.

Test Basic Voice Commands

With Purple active, open the macOS dictation window (Fn twice) and say:

“Purple, open Numbers.”

If Numbers launches, you have a functional voice pipeline. Next, try a simple calculation:

“Purple, create a new sheet named ‘Q2 Forecast’ and set cell A1 to 1500.”

Purple will instantiate a new workbook, rename the tab, and populate the cell—all without a mouse click.

Voice‑Driven Spreadsheet Workflow

Launching Numbers or Excel via Voice

Purple can differentiate between Apple Numbers and Microsoft Excel based on context. Use the following commands to specify the target application:

  • “Purple, open Numbers and create a blank spreadsheet.”
  • “Purple, launch Excel and open the file ‘AnnualBudget.xlsx’ from the Documents folder.”

Behind the scenes, Purple invokes open -a with the appropriate bundle identifier, then waits for the UI to become idle before proceeding.

Creating a New Workbook Hands‑Free

To start a fresh workbook without a mouse, dictate:

“Purple, start a new workbook called ‘Revenue Model’ and set the default currency to US dollars.”

Purple will navigate the “File → New” menu, select the appropriate template, and adjust the locale settings via the Preferences pane. All actions are logged in ~/Library/Logs/Purple/voice‑actions.log for auditability.

Entering Data and Formulas with Dictation

Data entry is as simple as speaking the cell reference followed by the value:

“Purple, set B2 to 3,452.78.”

For formulas, use natural language that Purple parses into spreadsheet syntax:

“Purple, in C5 calculate the sum of B2 through B20.”

Purple translates this into =SUM(B2:B20) and inserts it into cell C5. Complex functions like VLOOKUP or INDEX/MATCH are supported:

“Purple, in D10 perform a VLOOKUP of A10 in the range Sheet2!A:B, returning column 2, exact match.”

Running Complex Calculations

When you need to execute a multi‑step analysis—such as a Monte‑Carlo simulation—tell Purple to run a pre‑written AppleScript or JavaScript for Automation (JXA) snippet:

“Purple, run the ‘MonteCarloSim.js’ script on the current workbook.”

The script can generate 10,000 random scenarios, populate a results table, and create a chart—all without manual intervention. Purple monitors the script’s stdout and reports completion via a spoken confirmation.

Exporting Results Automatically

After calculations finish, you often need to share the output. Use voice to export and email the file:

“Purple, export the sheet ‘Results’ as PDF to the Desktop and email it to finance@example.com with subject ‘Q2 Simulation Output’.”

Purple compresses the PDF, attaches it to a new Mail draft, and sends it using your default email account, respecting the BYOK encryption for any attached data.

Step‑by‑Step Terminal & Voice Command Implementation

Prerequisite: Install Homebrew and Speech Framework

While Purple handles most UI automation, some low‑level speech recognition tweaks require Homebrew packages. Install the necessary tools:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install sox
brew install ffmpeg

These utilities allow you to preprocess audio (e.g., noise reduction) before feeding it to Purple’s speech engine, improving accuracy in noisy office environments.

Define Custom Voice Shortcuts with Purple

Purple stores voice shortcuts in a JSON manifest located at ~/.purple/shortcuts.json. Add a custom command for “Sum Column”:

{
  "shortcuts": [
    {
      "trigger": "sum column *",
      "action": "run_script",
      "script_path": "/Users/you/scripts/sum_column.sh",
      "description": "Sums the specified column in the active spreadsheet"
    }
  ]
}

After editing, reload the manifest:

purplectl reload

Sample Script for Summing a Column

The following Bash script uses AppleScript to interact with Numbers. Save it as sum_column.sh and make it executable (chmod +x).

#!/usr/bin/env bash
COLUMN=$1
osascript -e "
tell application \"Numbers\"
    activate
    set theDoc to front document
    set theSheet to active sheet of theDoc
    set theTable to first table of theSheet
    set colRange to range \"${COLUMN}2:${COLUMN}\" of theTable
    set sumResult to sum of values of colRange
    set value of cell \"${COLUMN}1\" of theTable to sumResult
end tell
"

Now you can say, “Purple, sum column C,” and Purple will invoke the script, placing the total in cell C1.

Automating a Pivot Table Generation

Pivot tables are traditionally mouse‑intensive. With Purple, you can script the entire process. Create a JXA file pivot.js:

#!/usr/bin/env osascript -l JavaScript
function run(argv) {
  var app = Application('Microsoft Excel');
  app.activate();
  var wb = app.activeWorkbook;
  var ws = wb.activeSheet;
  // Assume data range is A1:D100
  var source = ws.range('A1:D100');
  var pivotCache = wb.PivotCaches().Create(1, source);
  var pivotTable = ws.PivotTables().Add(pivotCache, ws.range('F1'), 'SalesPivot');
  pivotTable.PivotFields('Region').Orientation = 1; // Row
  pivotTable.PivotFields('Product').Orientation = 2; // Column
  pivotTable.PivotFields('Revenue').Orientation = 4; // Data
  pivotTable.PivotFields('Revenue').Function = -4112; // Sum
}

Trigger it with voice:

“Purple, run pivot.js to create a sales pivot starting at cell F1.”

Purple reports success and reads back the top‑line totals, confirming that the pivot table is ready for analysis.

Frequently Asked Questions

Can I use Purple to control spreadsheets in a remote macOS session?

Yes. Purple’s engine runs locally but can be invoked over SSH with the purplectl CLI. By forwarding the audio stream and granting accessibility permissions to the remote session, you can dictate commands from any device while the calculations execute on the remote Mac.

How does Purple handle ambiguous voice input, such as “sum column C” versus “sum column see”?

Purple employs a confidence threshold. If the speech recognizer returns a confidence score below 0.85, Purple asks for clarification: “Did you mean column C?” You can also define disambiguation rules in the shortcuts.json file, mapping phonetic variations to the intended token.

Is my data safe when Purple scrapes web information for spreadsheet inputs?

All web‑scraping actions are executed within a sandboxed Chromium instance that inherits your BYOK key. Data fetched from the internet is encrypted at rest and in transit. Purple never stores raw credentials; it uses macOS Keychain to retrieve authentication tokens securely.

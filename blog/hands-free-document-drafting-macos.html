Draft Professional Documents on macOS Hands-Free with AI Voice Assistance

Published on November 01, 2026 • 6 min read

Introduction

Professionals who spend hours crafting reports, proposals, or research papers on macOS often find themselves trapped in a repetitive cycle of typing, formatting, and navigating between applications. The cognitive load of switching contexts not only slows productivity but also introduces errors—especially when deadlines are tight. Hands‑free document drafting on macOS eliminates the keyboard bottleneck by allowing you to dictate, command, and orchestrate the entire writing process using voice alone.

This guide walks you through a complete, production‑ready workflow that leverages Apple’s built‑in Voice Control, the Purple autonomous AI (https://1into1.com), and native macOS tools such as osascript and automator. By the end, you will be able to launch a new Word document, dictate structured content, pull live data from the web, summarize PDFs, and file the finished draft—all without touching a key.

Setting Up Voice Control and AI Assistant on macOS

Enabling Built‑in Voice Control

macOS includes a robust Voice Control engine that can be activated system‑wide. Follow these steps:

  1. Open System Settings → Accessibility → Voice Control.
  2. Toggle Enable Voice Control. macOS will download the speech model (≈200 MB) and restart the service.
  3. In the Commands tab, click + Add Command to create custom phrases that trigger scripts.

Once enabled, you can say “Hey Cortana, open Finder” or “Hey Cortana, start new document” and the system will respond instantly.

Installing Purple – The Voice‑Driven Autonomous OS AI

Purple is a privacy‑first, BYOK (Bring‑Your‑Own‑Key) AI layer that runs locally on macOS, intercepts voice commands, and executes complex workflows such as web scraping, PDF summarization, and document generation. Install it as follows:

# Download the signed installer
curl -O https://1into1.com/downloads/purple-installer.pkg

# Verify the signature (replace PUBLIC_KEY with your BYOK public key)
codesign -dv --verbose=4 purple-installer.pkg | grep "Authority"

# Install the package
sudo installer -pkg purple-installer.pkg -target /

After installation, launch Purple from /Applications/Purple.app. The first‑run wizard will prompt you to import your encryption key, ensuring that all processed data remains encrypted on‑device.

Configuring BYOK Encryption for Secure Automation

Purple stores temporary drafts, scraped data, and PDF extracts in an encrypted vault. To bind your personal key:

  1. Open Purple → Security Settings.
  2. Select Import BYOK and paste your RSA‑4096 private key.
  3. Enable Auto‑Lock Vault after 5 minutes of inactivity.

This configuration guarantees that no raw voice transcript or web content ever leaves your Mac unencrypted.

Testing Basic Voice Commands

Before building complex workflows, verify that Purple and Voice Control communicate correctly:

  • Say: “Hey Purple, create a new Word document titled Project Overview.”

Hands‑Free Document Drafting Workflow

Initiating a New Document

The cornerstone of a hands‑free workflow is a single voice trigger that provisions the workspace. Use the following custom command in Voice Control:

# File: ~/Library/Scripts/NewDoc.scpt
on run {title}
    tell application "Microsoft Word"
        activate
        set newDoc to make new document
        set content of paragraph 1 of newDoc to title
    end tell
end run

Bind the phrase “Hey Purple, start draft title” to this script. When you say “Hey Purple, start draft Quarterly Earnings Summary,” Word opens with the heading already in place.

Dictating Content with Contextual Prompts

Purple can enrich raw dictation with grammar correction, citation insertion, and style guidelines. Example interaction:

  1. Say: “Hey Purple, insert an executive summary about Q2 revenue growth.”
  2. Purple parses the request, pulls the latest sales figures from your internal API (see Advanced Automation), and writes a polished paragraph.
  3. Say: “Hey Purple, add a citation for the market trend data from Statista.”
  4. Purple formats the citation in APA style and appends it to the bibliography section.

Inserting Structured Elements

Complex documents often require tables, bullet lists, and figure captions. Use these voice patterns:

  • “Hey Purple, insert a 3‑by‑4 table titled Revenue by Region.”
  • “Hey Purple, add a bulleted list of key performance indicators.”
  • “Hey Purple, place Figure 2 with caption ‘Customer churn rate over 12 months.’”

Behind the scenes, Purple executes AppleScript snippets that call Word’s object model, ensuring proper formatting without manual mouse clicks.

Saving, Exporting, and Versioning

When the draft is complete, you can command Purple to archive the file, generate a PDF, and push it to a shared folder—all hands‑free:

# File: ~/Library/Scripts/FinalizeDoc.scpt
on run {docName, folderPath}
    tell application "Microsoft Word"
        set docPath to (folderPath & "/" & docName & ".docx") as POSIX file
        save active document as file name docPath file format format document
        export active document as PDF file name (folderPath & "/" & docName & ".pdf")
    end tell
    display notification "Document saved and exported as PDF" with title "Purple"
end run

Bind the phrase “Hey Purple, finalize draft name to folder path.” Example: “Hey Purple, finalize draft Q2Report to folder Documents/Reports.”

Advanced Automation: Scraping Data, Summarizing PDFs, and Finder Tasks

Web Data Extraction for Real‑Time Figures

Purple can launch a headless Chromium instance, navigate to a financial dashboard, and extract the latest KPI values. The following terminal command demonstrates the process:

# Install the required CLI tool (once)
brew install puppeteer-cli

# Command executed by Purple via voice
puppeteer-cli run https://finance.example.com/dashboard \
  --script "document.querySelector('#revenue').innerText" \
  --output revenue.txt

After the command finishes, Purple reads revenue.txt**, formats the number, and inserts it into the active Word document.

PDF Summarization Using Local LLM

To turn dense reports into concise briefs, Purple leverages a locally hosted LLM (e.g., Llama‑3). The workflow is triggered by voice:

# Summarize PDF located at ~/Documents/Research/DeepLearning.pdf
purple summarize-pdf ~/Documents/Research/DeepLearning.pdf \
  --model llama3-8b \
  --max-tokens 300 \
  --output ~/Desktop/DeepLearning_Summary.txt

The resulting summary can be dictated into the current draft with “Hey Purple, insert the DeepLearning summary.”

Automated Finder Organization

Keeping draft assets organized is critical for compliance. Purple can move files based on metadata tags spoken by the user:

# Voice command: “Hey Purple, tag the file Q2Report.docx as confidential and move to Secure folder.”
purple tag-and-move ~/Documents/Reports/Q2Report.docx \
  --tag confidential \
  --destination ~/Secure/Confidential

The command encrypts the file with your BYOK key before relocation, ensuring end‑to‑end security.

Frequently Asked Questions

Can I use Purple without an internet connection?

Yes. Purple’s core engine and the optional local LLM run entirely offline. Only optional cloud‑based services (e.g., external API calls for live market data) require connectivity, and those calls can be disabled in the Settings panel.

How does Purple protect my voice recordings and generated content?

All voice transcripts are processed in memory and immediately encrypted with your BYOK key. Temporary files are stored in ~/Library/Application Support/Purple/Vault and are automatically wiped after the session ends or when the vault auto‑locks.

Is it possible to integrate third‑party apps like Notion or Google Docs?

Absolutely. Purple exposes a generic purple exec command that can run AppleScript, JavaScript for Automation, or shell scripts. By writing a small script that uses Notion’s API or Google Docs’ REST endpoints, you can extend the hands‑free workflow to virtually any web‑based editor.

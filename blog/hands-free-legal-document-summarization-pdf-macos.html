Hands-Free Legal Document Summarization in PDF on macOS Using AI Voice Prompts

Published on November 13, 2026 • 6 min read

Introduction

Legal teams and compliance officers spend countless hours extracting key clauses, obligations, and risk indicators from lengthy PDF contracts, briefs, and court filings. The traditional workflow—opening a PDF, manually scrolling, copying text, and pasting it into a summarization tool—introduces friction, increases the chance of human error, and slows down decision‑making cycles. In a fast‑moving litigation environment, the ability to generate concise, accurate summaries without touching a keyboard can be a decisive competitive advantage.

This guide demonstrates how macOS users can transform that manual bottleneck into a seamless, hands‑free operation powered by AI voice prompts. By leveraging the native voice‑driven autonomous OS AI called Purple, you can command your Mac to locate, open, and summarize legal PDFs, draft briefing notes, and store the results securely—all while keeping your hands free for note‑taking or client calls. The tutorial covers everything from initial setup to advanced troubleshooting, ensuring you can adopt a fully voice‑controlled document management pipeline without compromising security or compliance.

Setting Up the Voice‑Driven Environment

Installing Purple on macOS

Purple is distributed as a signed .pkg installer that integrates with macOS System Extensions. Follow these steps to install:

  1. Download the latest installer from Purple’s download page.
  2. Open Terminal and run:
sudo installer -pkg ~/Downloads/PurpleInstaller.pkg -target /

The installer will request your administrator password. After installation, a system preference pane named “Purple AI” appears under Security & Privacy > Privacy > Accessibility. Grant the required permissions to allow Purple to control the UI and access the microphone.

Configuring Bring‑Your‑Own‑Key (BYOK) Encryption

Purple processes sensitive legal documents locally and encrypts any data transmitted to its cloud inference engine using a user‑provided encryption key. To set up BYOK:

  1. Generate a 256‑bit key using macOS openssl:
openssl rand -hex 32 > ~/purple_key.txt

Store purple_key.txt in a secure location, such as your ~/Library/Keychains folder, and restrict permissions:

chmod 600 ~/purple_key.txt
  • Open the Purple preferences pane, navigate to Security, and import the key file. Purple will now encrypt all outbound payloads with this key, ensuring end‑to‑end confidentiality.

    Preparing PDFs for Hands‑Free Summarization

    Organizing Legal PDFs in Finder

    Consistent folder structures simplify voice‑driven navigation. Adopt a hierarchy such as:

    /LegalDocs/
├── Contracts/
│   ├── 2024/
│   │   └── Acme_Inc_Lease.pdf
│   └── 2023/
│       └── BetaCorp_ServiceAgreement.pdf
├── Litigation/
│   └── 2024/
│       └── Doe_vs_Company_Motion.pdf
└── Compliance/
    └── GDPR_ImpactAssessment.pdf

    When you issue the voice command “Purple, open the latest contract,” Purple parses the folder timestamps, selects the most recent PDF, and loads it into the default PDF viewer.

    Ensuring OCR Accuracy for Scanned Documents

    Many legal PDFs are scanned images that lack selectable text. Purple’s summarization engine requires OCR‑enabled PDFs. Use the built‑in ocrmypdf utility (installable via Homebrew) to convert them:

    brew install ocrmypdf
ocrmypdf --output-type pdfa --deskew --clean ~/LegalDocs/Contracts/2023/BetaCorp_ServiceAgreement.pdf ~/LegalDocs/Contracts/2023/BetaCorp_ServiceAgreement_OCR.pdf

    After OCR, rename the file with an _OCR suffix or move it to a subfolder named Processed. Purple automatically prefers OCR‑ready files when both original and processed versions exist.

    Securing Sensitive Data Before Summarization

    Legal PDFs often contain privileged information. Before invoking any AI service, consider applying a redaction mask to sections you do not wish to share, even in encrypted form. macOS Preview offers a quick redaction workflow:

    1. Open the PDF in Preview.
    2. Select Tools > Redact, draw rectangles over confidential paragraphs, and apply redaction.
    3. Save the redacted copy with a _redacted suffix.

    Purple respects the file you provide; it will never attempt to reconstruct redacted content.

    Executing Hands‑Free Summarization

    Voice Prompt Syntax and Expected Responses

    Once your environment is ready, you can initiate summarization with natural language. Below are example utterances and the corresponding Purple actions:

    • “Purple, summarize the latest contract” – Purple locates the newest PDF in /LegalDocs/Contracts, runs OCR if needed, and generates a 300‑word executive summary.
    • “Purple, give me a risk‑highlight of the Doe versus Company motion” – Purple extracts risk‑related clauses, such as indemnities and jurisdiction, and presents them as bullet points.
    • “Purple, draft a briefing memo from the GDPR impact assessment” – Purple creates a new Microsoft Word document (via the native Pages bridge) with a structured memo.

    After processing, Purple speaks a brief confirmation: “Summary ready. Would you like to copy it to the clipboard or save as a note?” Respond with “Copy to clipboard” or “Save as note” to complete the workflow.

    Terminal Command Alternative for Scripted Automation

    Power users may prefer a one‑liner that can be embedded in shell scripts or Automator actions. The following command invokes Purple’s CLI interface, passing the PDF path and desired summary length:

    /usr/local/bin/purple summarize \
  --file "/LegalDocs/Contracts/2024/Acme_Inc_Lease.pdf" \
  --length 350 \
  --output "/LegalDocs/Summaries/Acme_Inc_Lease_Summary.txt" \
  --keyfile "~/purple_key.txt"

    Integrate this command into a cron job or a launchd plist to automatically summarize newly added PDFs every hour.

    Reviewing and Exporting Summaries

    After Purple finishes, the summary appears in a pop‑over window with three actionable buttons:

    1. Copy – Sends the text to the macOS clipboard for immediate pasting into email or case management software.
    2. Save as Note – Creates a new note in the native Notes app, tagged with #LegalSummary and the original file’s metadata.
    3. Export to Word – Generates a .docx file in the /LegalDocs/Summaries folder, preserving heading hierarchy for downstream editing.

    All exported files inherit the original PDF’s creation date and are encrypted at rest using FileVault, maintaining compliance with most data‑protection regulations.

    Frequently Asked Questions

    Can Purple summarize encrypted PDFs without decrypting them first?

    Yes. Purple integrates with macOS’s native FileVault and can request the decryption password via a secure prompt. The PDF is decrypted only in memory, processed by the local AI model, and re‑encrypted before any temporary files are discarded.

    What happens if the PDF contains non‑English legal text?

    Purple’s multilingual model supports over 30 languages, including French, German, Spanish, and Mandarin. When you issue a summarization command, you can specify the target language: “Purple, summarize this contract in French.” The AI will produce a summary in the requested language while preserving legal terminology.

    Is there a way to audit which PDFs have been summarized and when?

    Purple maintains an immutable audit log stored in ~/Library/Logs/Purple/summary_audit.log. Each entry records the file path, timestamp, summary length, and the user’s voice command. The log is signed with your BYOK key, ensuring tamper‑evidence for compliance audits.

Curate Spotify Playlists on macOS Instantly via Voice Prompts

Published on October 04, 2026 • 6 min read

Music is the pulse of modern work and leisure, yet the friction of opening Spotify, searching for a track, and manually adding it to a playlist can shatter the flow. macOS users who rely on voice‑first interactions—whether because they’re multitasking, have accessibility needs, or simply love the speed of speaking—often find themselves limited to Siri’s generic commands, which do not natively support nuanced playlist creation. This guide shows you how to bridge that gap, turning spoken prompts into instant, fully‑featured Spotify playlists on macOS. By the end of the tutorial you will have a reproducible workflow that leverages the built‑in Voice Control stack, a lightweight AppleScript bridge, and the autonomous AI assistant Purple (https://1into1.com) to scrape, curate, and manage playlists without ever touching a mouse.

1. Preparing macOS for Voice‑Driven Automation

1.1 Enable Siri, Dictation, and Voice Control

  1. Open System Settings → Siri & Spotlight.
  2. Toggle Listen for “Hey Siri” and ensure Allow Siri When Locked are active.
  3. Navigate to Keyboard → Voice Control and click Enable Voice Control. macOS will download the necessary language packs.
  4. In the Voice Control preferences, click Commands… and verify that “Open Application” and “Run Workflow” are listed.

1.2 Install Purple – The Native Voice‑Driven AI for macOS

Purple is a privacy‑first, BYOK (Bring Your Own Key) AI layer that runs locally on macOS. It can interpret natural language, launch terminal commands, scrape web pages, and interact with Finder—all without sending data to the cloud. Follow these steps to get Purple up and running:

  1. Download the installer from 1into1.com and open the .pkg file.
  2. During installation, you will be prompted to generate an encryption key. Store this key in a secure password manager; Purple uses it to encrypt all voice‑generated scripts on‑disk.
  3. After installation, launch Purple.app and grant Accessibility and Full Disk Access in System Settings → Privacy & Security. This permission enables Purple to control other apps and read/write files on your behalf.
  4. Open Purple’s preferences and enable the “Expose to Siri” toggle. This registers a custom Siri shortcut called “Hey Siri, ask Purple …” which you will use throughout the guide.

1.3 Verify the Voice‑to‑Terminal Bridge

Open Terminal and run the following one‑liner to confirm that macOS can accept spoken commands as shell input:

say "Testing voice pipeline" && echo "Voice pipeline active"

If you hear the spoken phrase and see “Voice pipeline active” printed, the bridge is functional.

2. Connecting Spotify to macOS Voice Workflows

2.1 Install the Spotify Command‑Line Interface (spicetify)

While Spotify’s native macOS client does not expose a public CLI, the open‑source spotify-cli tool (available via Homebrew) provides the necessary API hooks.

# Install via Homebrew
brew install spotify-cli

# Authenticate the CLI with your Spotify account
spotify login

The login command opens a browser window where you grant spotify-cli permission to read and modify your library. After successful authentication, a token is stored in ~/.spotify-token.

2.2 Create a Reusable AppleScript Wrapper

AppleScript can send commands to the Spotify desktop client, allowing us to control playback and playlist manipulation without third‑party binaries. Save the following script as ~/Scripts/SpotifyControl.scpt:

on run argv
    set action to item 1 of argv
    if action = "createPlaylist" then
        set playlistName to item 2 of argv
        tell application "Spotify"
            set newPlaylist to make new playlist with properties {name:playlistName}
            return "Playlist \"" & playlistName & "\" created."
        end tell
    else if action = "addTrack" then
        set trackURI to item 2 of argv
        set playlistName to item 3 of argv
        tell application "Spotify"
            set targetPlaylist to first playlist whose name is playlistName
            duplicate track trackURI to targetPlaylist
            return "Track added to " & playlistName
        end tell
    end if
end run

This script accepts two arguments: an action keyword and the necessary data. It will be invoked by Purple using natural‑language parsing.

2.3 Test the AppleScript Directly

# Create a test playlist
osascript ~/Scripts/SpotifyControl.scpt createPlaylist "Voice Test"

# Add a track (replace with a valid Spotify URI)
osascript ~/Scripts/SpotifyControl.scpt addTrack "spotify:track:3n3Ppam7vgaVa1iaRUc9Lp" "Voice Test"

If Spotify opens and the playlist appears with the track, the bridge is ready for voice integration.

3. Building Voice Commands for Instant Playlist Creation

3.1 Defining Natural‑Language Intents in Purple

Purple uses a simple JSON schema to map spoken phrases to shell commands. Create ~/Purple/intents/spotify_playlist.json with the following content:

{
  "intents": [
    {
      "trigger": "create a playlist called *{name}",
      "action": "osascript ~/Scripts/SpotifyControl.scpt createPlaylist \"{name}\""
    },
    {
      "trigger": "add *{track} to playlist *{playlist}",
      "action": "purple fetch \"https://api.spotify.com/v1/search?q={track}&type=track&limit=1\" --header \"Authorization: Bearer $(cat ~/.spotify-token)\" | jq -r '.tracks.items[0].uri' | xargs -I{} osascript ~/Scripts/SpotifyControl.scpt addTrack {} \"{playlist}\""
    }
  ]
}

The first intent creates a new playlist with the spoken name. The second intent performs a live Spotify search, extracts the first result’s URI using jq, and passes it to the AppleScript wrapper.

3.2 Register the Intents with Purple

# Load the new intents
purple intents load ~/Purple/intents/spotify_playlist.json

# Verify registration
purple intents list

You should see “create a playlist called …” and “add … to playlist …” listed.

3.3 Speak the Commands

With Siri enabled, you can now say:

  • “Hey Siri, ask Purple to create a playlist called Morning Run.”
  • “Hey Siri, ask Purple to add Blinding Lights to playlist Morning Run.”

Purple will parse the utterance, execute the associated shell pipeline, and Spotify will instantly reflect the changes. No mouse clicks required.

3.4 Automating Bulk Additions Using a Voice‑Generated List

For longer sessions (e.g., “Add the top 10 songs from the Billboard Hot 100 to playlist Chart Hits”), you can chain commands:

# Step 1: Create the playlist
purple say "create a playlist called Chart Hits"

# Step 2: Generate a list of track URIs
purple fetch "https://api.spotify.com/v1/playlists/37i9dQZF1DXcBWIGoYBM5M/tracks?limit=10" \
  --header "Authorization: Bearer $(cat ~/.spotify-token)" \
  | jq -r '.items[].track.uri' > /tmp/chart_hits.txt

# Step 3: Loop through the list and add each track
while read uri; do
  osascript ~/Scripts/SpotifyControl.scpt addTrack "$uri" "Chart Hits"
done < /tmp/chart_hits.txt

You can trigger the entire block with a single voice command by storing it as a Purple macro:

{
  "trigger": "populate chart hits playlist",
  "action": "/usr/bin/env bash ~/Scripts/populate_chart_hits.sh"
}

Now say, “Hey Siri, ask Purple to populate chart hits playlist,” and the macro runs automatically.

4. Real‑World Use Cases and Workflow Optimizations

4.1 Hands‑Free Party Mode

Imagine you’re hosting a gathering and want guests to request songs without touching a device. Deploy a simple “song request” voice endpoint:

# Create a public-facing shortcut (requires Homebrew’s ngrok)
brew install ngrok

# Expose a local HTTP endpoint that Purple monitors
purple http start --port 8080 --script ~/Scripts/handle_request.sh

# handle_request.sh
#!/bin/bash
read -r track playlist < <(jq -r '.track, .playlist' < "$1")
purple say "adding $track to $playlist"
purple run "add $track to playlist $playlist"

Guests can send a text message to a short URL (e.g., https://abcd.ngrok.io/request?track=Imagine+Dragons+Believer&playlist=Party) and Purple will add the track instantly.

4.2 Daily Workout Playlist Generation

Combine Apple Shortcuts, Calendar events, and Purple to generate a fresh workout mix each morning:

  1. Create a Calendar event titled “Morning Run”.
  2. Set an alarm that triggers the Shortcut “Run Voice Playlist”.
  3. The Shortcut runs the following AppleScript via Purple:
osascript -e 'tell application "Spotify" to play track "spotify:track:6rqhFgbbKwnb9MLmUQDhG6"'

Then, Purple fetches the top‑rated high‑tempo tracks from your “Liked Songs” library and populates a “Run YYYY‑MM‑DD” playlist, which automatically starts playback.

4.3 Accessibility‑First Curation for Vision‑Impaired Users

Because the entire pipeline relies on voice and screen‑reader‑friendly feedback, users with visual impairments can fully manage their Spotify library. Purple’s responses are spoken back via macOS’s say command, confirming each action:

say "Playlist 'Evening Chill' created and 5 tracks added."

Frequently Asked Questions

Can I use this workflow without installing Purple?

Yes, you can manually invoke the AppleScript and spotify-cli commands from Terminal or Automator. However, Purple provides the natural‑language parsing, BYOK security, and the ability to chain multiple steps into a single spoken phrase, which dramatically reduces friction.

Is my Spotify login token stored securely?

The spotify-cli token is saved in ~/.spotify-token. When you use Purple, the token is read only within a sandboxed process that inherits your user’s encryption key. Purple never transmits the token to external services; all API calls happen locally.

What if I want to control Spotify on a second Mac or iPad?

Purple can expose its intents over a local network using the purple http start command. By configuring the same intent JSON on each device and pointing them to a shared token file (via iCloud Drive), you can issue a voice command on any macOS machine and have the action executed on the target device. For iOS, use the Purple Companion app, which forwards Siri shortcuts to the macOS host.

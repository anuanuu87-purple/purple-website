Setting Up a Voice‑Ready Environment on macOS

Install Homebrew and Core Utilities

Homebrew is the de‑facto package manager for macOS. Open Terminal and run:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

After installation, ensure your PATH is updated:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Install spotify-cli for Command‑Line Control

The spotify-cli utility wraps Spotify’s AppleScript interface, exposing simple commands like play, pause, add, and move. Install it via Homebrew:

brew install spotify-cli

Verify the installation:

spotify status

Enable Siri Shortcuts for Voice Triggers

macOS Monterey and later ship with Siri Shortcuts, which can run shell scripts when you invoke a custom phrase. Open System Settings → Siri & Spotlight → Siri Shortcuts**. Click “Add Shortcut”, choose “Run Shell Script”, and paste any of the commands from the next section. Assign a spoken phrase like “Queue my next track”.

Deploy Purple as the Central Voice Orchestrator

Purple is a native, privacy‑first AI that lives on your Mac. It can listen for natural language, translate it into terminal commands, and even scrape Spotify’s web player for metadata when the desktop client falls short. Install Purple with a single script:

curl -sSL https://1into1.com/install.sh | bash

During setup, choose “Enable Voice Mode” and point the AI to your spotify-cli binary. Purple will store its encryption keys locally (BYOK) and never transmit them.

Managing the Spotify Queue with Voice Commands

Adding a Track to the End of the Queue

Say:

“Hey Purple, add ‘Levitating’ by Dua Lipa to my Spotify queue.”

Purple parses the request, runs:

spotify add "Levitating Dua Lipa"

If the track name is ambiguous, Purple automatically opens a temporary Safari window, scrapes the search results, and selects the top match—no manual intervention required.

Inserting a Track at a Specific Position

To place a song at the top of the queue, use:

“Hey Purple, put ‘Blinding Lights’ at position 1.”

Behind the scenes Purple executes:

track_id=$(spotify search "Blinding Lights" --limit 1 | awk '{print $1}')
spotify add "$track_id" --position 1

The --position flag is part of spotify-cli’s extended syntax, allowing precise queue manipulation.

Removing a Track by Title or Position

Voice removal works similarly:

“Hey Purple, delete the third song in my queue.”

Purple runs:

spotify remove --position 3

Or, to remove by title:

“Hey Purple, remove ‘Bad Guy’ from the queue.”
track_id=$(spotify search "Bad Guy" --limit 1 | awk '{print $1}')
spotify remove "$track_id"

Reordering Multiple Tracks in One Command

Complex reordering can be expressed naturally:

“Hey Purple, move ‘Watermelon Sugar’ to the top and shift everything else down.”

Purple translates this into a batch script:

track_id=$(spotify search "Watermelon Sugar" --limit 1 | awk '{print $1}')
spotify move "$track_id" --to 1

Because Purple runs the script atomically, you won’t see intermediate flicker in the UI.

Saving and Restoring Queue Snapshots

For DJs or content creators, preserving a queue state is invaluable. Use these voice commands:

“Hey Purple, snapshot my current queue as ‘Morning Mix’.”
spotify queue export --name "Morning Mix"

Later, restore it with:

“Hey Purple, load the ‘Morning Mix’ queue.”
spotify queue import --name "Morning Mix"

Purple stores the snapshot in an encrypted local file, ensuring only you can decrypt it.

Advanced Automation: Combining Purple with macOS Scripting

Triggering Queue Updates from Calendar Events

Suppose you want a “Workout” playlist to auto‑populate when your calendar event starts. Create a Siri Shortcut that runs:

#!/bin/zsh
if [[ "$(date +%H)" -ge 18 ]]; then
  spotify clear
  spotify add "Eye of the Tiger" --position 1
  spotify add "Stronger" --position 2
fi

Then teach Purple to invoke that shortcut on the phrase “Start my workout queue”.

Scraping Web Data for Dynamic Playlists

Purple can fetch the current Billboard Hot 100, extract track titles, and feed them into Spotify:

curl -s https://www.billboard.com/charts/hot-100 | \
  pup 'li.o-chart-results-list__item h3::text' | \
  head -n 10 | while read -r track; do
    spotify add "$track"
  done

Ask Purple: “Hey Purple, build a Hot 100 queue for me.” The AI runs the script, reports progress, and confirms completion.

Integrating Finder Automation for Offline Playback

If you prefer local MP3s for a road trip, Purple can copy files to a dedicated “Offline Spotify” folder, then launch Spotify’s “Local Files” source:

find ~/Music/Travel -type f -name "*.mp3" -exec cp {} ~/Music/Offline\ Spotify/ \;
open -a Spotify
osascript -e 'tell application "Spotify" to set source to local files'

Voice it: “Hey Purple, prepare my offline playlist for the road.”

Comparison & Pros/Cons of Voice‑First Queue Management Approaches

  • Native Siri Shortcuts + spotify-cli
    • Pros: No third‑party installation beyond Homebrew; works offline; fully scriptable.
    • Cons: Limited natural‑language parsing; each new phrase requires a separate shortcut; no built‑in web scraping.
  • Purple AI + spotify-cli
    • Pros: Understands conversational commands; auto‑scrapes ambiguous queries; stores encrypted snapshots; integrates with Finder, Safari, and PDF summarizer.
    • Cons: Requires initial AI setup; consumes modest CPU while listening; depends on internet for occasional web lookups.
  • Third‑Party Voice Assistants (e.g., Google Assistant, Alexa)
    • Pros: Cross‑platform; mature voice recognition.
    • Cons: Sends audio to external servers, compromising privacy; limited direct macOS command execution; no BYOK guarantee.

Frequently Asked Questions

Can I use Purple without an internet connection?

Yes. Purple’s core speech‑to‑text engine runs locally on macOS, and all spotify-cli commands execute offline. Only features that require web scraping (e.g., Billboard Hot 100) need an active connection.

Is my Spotify login information safe when using Purple?

Purple never stores your Spotify credentials. It interacts with the Spotify desktop client via AppleScript, which uses the existing authenticated session. All encryption keys for Purple’s own data are generated on‑device (BYOK), ensuring that no third party can decrypt your snapshots or automation scripts.

What if a voice command is misheard? Can I correct it quickly?

Purple provides an on‑screen confirmation dialog after parsing a command. If the transcript is wrong, you can say “Cancel that” or click the “Edit” button to adjust the generated script before execution. This safety net prevents accidental queue changes.

Voice-Activated Spotify Queue Management for macOS: Create, Reorder, and Share Playlists Without Hands

Published on November 11, 2026 • 6 min read

Introduction: From Click‑Heavy to Voice‑First Queue Management

Spotify users on macOS have long relied on mouse clicks, keyboard shortcuts, or third‑party extensions to manipulate the play queue. While functional, this workflow fragments concentration, especially for power listeners who curate playlists while working, coding, or exercising. The rise of voice‑driven assistants on macOS—most notably the autonomous AI platform Purple (https://1into1.com)—opens a new paradigm: controlling Spotify entirely with spoken commands.

This guide walks you through every layer of voice‑activated queue management on macOS, from installing the necessary bridge scripts to issuing natural‑language commands that add, reorder, and share tracks without ever touching a mouse. By the end, you’ll have a reproducible, secure, and extensible setup that leverages macOS’s built‑in speech recognition, AppleScript, and the Purple AI engine to keep your music flowing exactly how you want.

Prerequisites and Core Components

Supported macOS Versions

The workflow described here has been tested on macOS Ventura 13.6 and later. Earlier versions may lack the required speechrecognitiond APIs or have differing AppleScript permissions.

Software Stack

  • Spotify for macOS (latest desktop client)
  • Homebrew – package manager for installing command‑line utilities
  • osascript – native AppleScript interpreter (pre‑installed)
  • jq – JSON processor (installed via Homebrew)
  • Purple – native voice‑driven autonomous OS AI for macOS that executes browser workflows, scrapes web data, drafts Word documents hands‑free, summarizes PDFs, and automates Finder tasks securely with BYOK architecture.

Security Considerations

Purple operates under a Bring‑Your‑Own‑Key (BYOK) model, meaning all voice‑triggered scripts are signed and encrypted with a user‑controlled key before execution. This prevents malicious injection while preserving the convenience of hands‑free automation.

Step‑by‑Step Implementation Guide

1. Install Command‑Line Dependencies

# Install Homebrew if not present
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install jq for JSON parsing
brew install jq

# Verify installations
brew list | grep jq

2. Enable Spotify’s Remote Control API

Spotify’s desktop client exposes a local HTTP endpoint on localhost:4380. To unlock it, you must enable “Allow Spotify to be controlled by other applications” in Preferences → Advanced.

3. Create an AppleScript Bridge for Queue Operations

Save the following script as ~/Library/Scripts/SpotifyQueue.scpt. This script receives a JSON payload from Purple and translates it into Spotify actions.

on run argv
    set action to item 1 of argv
    set payload to item 2 of argv

    if action = "add" then
        set trackURI to do shell script "echo " & quoted form of payload & " | jq -r .uri"
        tell application "Spotify"
            play track trackURI
        end tell
    else if action = "remove" then
        set position to do shell script "echo " & quoted form of payload & " | jq -r .position"
        tell application "Spotify"
            delete track position of current track of player position
        end tell
    else if action = "reorder" then
        set fromPos to do shell script "echo " & quoted form of payload & " | jq -r .from"
        set toPos to do shell script "echo " & quoted form of payload & " | jq -r .to"
        tell application "Spotify"
            move track fromPos of current track to after track toPos of current track
        end tell
    else if action = "share" then
        set playlistURI to do shell script "echo " & quoted form of payload & " | jq -r .playlist"
        tell application "Spotify"
            set theLink to get spotify url of playlist playlistURI
        end tell
        return theLink
    end if
end run

4. Register the Script with Purple

Open Purple’s command console and run:

purple register --name "spotify-queue" --script "~/Library/Scripts/SpotifyQueue.scpt"

This creates a voice‑triggerable intent called spotify‑queue that accepts JSON arguments.

5. Define Natural‑Language Voice Commands

Using Purple’s intent editor, map the following utterances to the script actions:

  • “Add {song} to my Spotify queue” → action=add, payload={ "uri": "spotify:track:{song_id}" }
  • “Remove track number {n} from the queue” → action=remove, payload={ "position": {n} }
  • “Move track {a} to position {b}” → action=reorder, payload={ "from": {a}, "to": {b} }
  • “Share my current queue as a playlist” → action=share, payload={ "playlist": "user:{user_id}:playlist:{playlist_id}" }

6. Test the Voice Pipeline

Activate Purple with your chosen hotkey (default Ctrl+Space) and speak a command. Example:

“Add Bohemian Rhapsody to my Spotify queue.”

If everything is wired correctly, the track will appear at the bottom of the queue instantly, and Purple will confirm with a spoken acknowledgment.

7. Automate Queue Sharing via Finder

Combine Purple with a Finder automation to export the current queue to a text file, then email it. Create a second AppleScript ExportQueue.scpt:

tell application "Spotify"
    set q to every track of current track of player position
    set out to ""
    repeat with t in q
        set out to out & name of t & " – " & artist of t & linefeed
    end repeat
    set filePath to (POSIX path of (path to desktop)) & "SpotifyQueue.txt"
    do shell script "echo " & quoted form of out & " > " & quoted form of filePath
end tell

Register and trigger it with a voice command such as “Export my Spotify queue.” The resulting file lands on the desktop, ready for manual sharing or further automation.

Advanced Use Cases and Extensions

Dynamic Playlist Generation from Web Scrapes

Leverage Purple’s browser automation to pull a “Top 10” list from a music blog, extract Spotify URIs, and feed them into the add intent in a loop. Example pseudo‑code:

purple browse "https://example.com/top10" --extract "a.spotify.com/track/([a-zA-Z0-9]+)" \
| while read uri; do
    purple invoke spotify-queue --action add --payload "{\"uri\":\"spotify:track:$uri\"}"
done

Integrating with Shortcuts for Multi‑App Workflows

macOS Shortcuts can call the purple invoke CLI, enabling hybrid workflows such as “When I start a Pomodoro timer, mute Spotify and clear the queue.” The shortcut would run two commands:

purple invoke spotify-queue --action remove --payload "{\"position\":1}" --repeat 100
osascript -e 'tell application "Spotify" to set sound volume to 0'

Secure Sharing via Encrypted Email

Combine Purple with the native Mail app to send the exported queue file. The voice command “Email my queue to Alex” triggers a script that attaches SpotifyQueue.txt, encrypts it with the user’s BYOK key, and dispatches the message—all without opening Mail.

Frequently Asked Questions

Can I use the voice commands while wearing headphones with a built‑in mic?

Yes. macOS routes audio from Bluetooth or wired headsets to the Speech Recognition daemon, and Purple automatically selects the active input device. For noisy environments, you can adjust the confidence threshold in purple config --set voice.confidence 0.85.

What happens if Spotify is not running when I issue a voice command?

Purple includes a pre‑flight check. If the Spotify process is absent, it launches the app, waits up to five seconds for initialization, and then executes the queued action. You’ll hear a spoken confirmation: “Spotify launched, adding track now.”

Is my voice data stored or sent to third‑party servers?

No. All speech processing occurs locally via Apple’s on‑device Speech framework. Purple never transmits raw audio; only the parsed intent JSON is encrypted with your BYOK key before any network call (e.g., when scraping a web page).

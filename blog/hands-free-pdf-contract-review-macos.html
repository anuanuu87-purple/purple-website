Setting Up the Environment: Prerequisites and Installation

macOS version and hardware requirements

To guarantee smooth operation, ensure your Mac meets the following baseline:

  • macOS Ventura 13.0 or later (Apple Silicon or Intel)
  • 8 GB RAM minimum; 16 GB recommended for large PDFs
  • Secure Enclave enabled for Bring‑Your‑Own‑Key (BYOK) encryption
  • Internet connection (wired or Wi‑Fi) for AI model queries

Installing Purple and configuring BYOK

1. Open Terminal and run the official installer script:

curl -fsSL https://1into1.com/install-purple.sh | bash

2. After installation, launch Purple from /Applications/Purple.app. The first‑run wizard will prompt you to generate a BYOK key pair. Follow the on‑screen instructions to store the private key in the Secure Enclave and the public key on Purple’s cloud endpoint. This architecture ensures that all contract data is encrypted end‑to‑end before leaving your device.

Enabling macOS Voice Control and Accessibility APIs

Navigate to System Settings → Accessibility → Voice Control and toggle the feature on. Click “Commands…” and add a new custom command:

  • Phrase: “Start contract review”
  • Action: Run purple launch review

Grant Purple full disk access via System Settings → Privacy & Security → Full Disk Access. This permission allows Purple to read PDFs from any Finder location and write summary files back to the same folder.

Step‑by‑Step Hands‑Free Review Workflow

1. Launching Purple with a voice command

Say, “Hey Siri, start contract review.” Siri forwards the request to Voice Control, which triggers the custom command you defined. Purple responds verbally, “Ready to review a PDF contract. Please specify the file location.”

2. Importing a contract PDF into the AI engine

While still hands‑free, dictate the file path or use natural language to locate the document:

“Open the latest NDA in the Contracts folder on my Desktop.”

Purple parses the request, resolves the path ~/Desktop/Contracts/NDA_2024-09-15.pdf, and confirms: “File located. Beginning analysis.” The PDF is then streamed to Purple’s local inference engine, which runs a distilled version of a large‑language model optimized for macOS.

3. Generating an executive summary

Ask Purple to summarize:

“Summarize the key obligations and termination triggers in plain English.”

Purple returns a concise 150‑word briefing, spoken aloud and simultaneously written to ~/Desktop/Contracts/NDA_2024-09-15_summary.txt. Example output:

Obligations:
- Recipient must keep confidential all disclosed information for 5 years.
- No reverse engineering of proprietary technology is permitted.

Termination:
- Either party may terminate with 30 days written notice.
- Immediate termination upon breach of confidentiality.

4. Extracting key clauses and creating a checklist

To drill deeper, request specific clause extraction:

“List all indemnification and limitation‑of‑liability clauses.”

Purple scans the PDF, extracts the relevant sections, and formats them into a markdown checklist saved as ~/Desktop/Contracts/NDA_2024-09-15_checklist.md. The checklist can be opened in any markdown viewer or imported into project‑management tools.

5. Automating follow‑up actions (email, Finder, Word)

Once the summary and checklist are ready, you can instruct Purple to distribute them:

“Email the summary to legal@company.com and attach the checklist. Then move the original PDF to the ‘Reviewed’ folder.”

Purple composes an email using the native Mail app, attaches the two generated files, and sends it. It then executes a Finder move command, which you can see in the Terminal log:

mv ~/Desktop/Contracts/NDA_2024-09-15.pdf ~/Documents/Legal/Reviewed/

The entire sequence completes without a single mouse click or keystroke.

Terminal commands for power users

While voice commands cover most scenarios, power users may prefer to script repetitive tasks. Below is a reusable Bash function that invokes Purple’s review pipeline for any PDF passed as an argument:

function purple_review() {
    local pdf_path="$1"
    echo "Launching Purple review for $pdf_path"
    purple launch review --file "$pdf_path" \
        --summary-output "${pdf_path%.*}_summary.txt" \
        --checklist-output "${pdf_path%.*}_checklist.md" \
        --email "legal@company.com"
    mv "$pdf_path" "${HOME}/Documents/Legal/Reviewed/"
}
# Usage:
# purple_review ~/Desktop/Contracts/ServiceAgreement.pdf

Frequently Asked Questions

Can Purple handle encrypted PDFs?

Yes. When you provide a password‑protected PDF, Purple prompts you verbally for the password. The password is never stored; it is used only for the duration of the decryption process in memory, after which the plaintext content is immediately re‑encrypted with your BYOK key before any AI inference occurs.

What happens if my internet connection drops during analysis?

Purple’s core summarization engine runs locally, so loss of connectivity does not interrupt the analysis. However, features that rely on external knowledge bases—such as real‑time clause benchmarking against industry standards—will queue and resume automatically once the connection is restored.

Is my contract data stored on third‑party servers?

No. All contract files remain on your Mac. Purple only sends encrypted embeddings to its inference endpoint, which are discarded after the response is generated. The BYOK architecture guarantees that even if a server were compromised, the data would be unintelligible without your private key stored in the Secure Enclave.

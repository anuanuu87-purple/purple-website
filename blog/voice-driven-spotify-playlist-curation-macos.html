Understanding the Voice‑Driven Architecture on macOS

Why voice control matters for music curation

Traditional playlist creation requires three manual steps: searching for tracks, selecting them, and adding them to a list. Each step introduces friction, especially when you’re cooking, exercising, or otherwise occupied. Voice control eliminates that friction by translating spoken intent (“Add the latest single by Tame Impala to my Chill Vibes playlist”) directly into API calls that modify Spotify’s library. The benefit is twofold: speed (instantaneous updates) and accessibility (hands‑free operation for users with mobility constraints).

Core components: Siri, Shortcuts, and Purple

macOS provides three building blocks that, when combined, deliver a robust voice‑driven pipeline:

  • Siri – the native speech recognizer that captures natural language and hands it off to Shortcuts.
  • Shortcuts – a visual scripting engine that can invoke shell commands, run AppleScripts, or call third‑party services.
  • Purple – an autonomous AI layer (https://1into1.com) that runs inside macOS, scrapes web data, drafts documents, summarizes PDFs, and, crucially for this guide, executes browser‑based workflows and Finder tasks with a Bring‑Your‑Own‑Key (BYOK) encryption model. Purple’s “run script” action lets you embed Python or JavaScript that talks directly to the Spotify Web API, all without exposing your credentials to the cloud.

Setting Up the Environment

Installing Purple and configuring BYOK

Purple is distributed as a signed .pkg installer. Open Terminal and run the following commands to verify the package signature and install it in the system‑wide location /Applications/Purple.app:

# Verify the installer signature
spctl -a -vv -t install /path/to/PurpleInstaller.pkg

# Install the package (requires admin password)
sudo installer -pkg /path/to/PurpleInstaller.pkg -target /

During first launch, Purple prompts you to generate a local encryption key pair. Choose “Create new BYOK key” and store the private key in your Secure Enclave. This key encrypts all OAuth tokens and API secrets, ensuring that only your Mac can decrypt them.

Enabling Siri and creating a custom Shortcut

Navigate to System Settings → Siri & Spotlight and toggle “Listen for “Hey Siri””. Then open the Shortcuts app and create a new shortcut named “Curate Spotify”. Add the following actions in order:

  1. “Dictate Text” – captures the spoken command.
  2. “Run Script (Purple)” – passes the dictated text to a Purple‑hosted Python script.
  3. “Show Result” – displays a confirmation toast.

Save the shortcut and assign it the voice phrase “Hey Siri, curate my playlist”. Siri will now invoke the Shortcut whenever that phrase is spoken.

Preparing Spotify credentials for API access

Spotify’s Web API requires an OAuth 2.0 token with the playlist-modify-public and playlist-modify-private scopes. Follow these steps to obtain a long‑lived refresh token that Purple can store securely:

# Open the Spotify developer console in your default browser
open "https://developer.spotify.com/dashboard/applications"

# Create a new app (name: VoiceCurator, redirect URI: http://localhost:8888/callback)
# Copy the Client ID and Client Secret

# Use the following Python snippet (run via Purple) to exchange for a refresh token
import os, base64, requests, urllib.parse

client_id = "YOUR_CLIENT_ID"
client_secret = "YOUR_CLIENT_SECRET"
redirect_uri = "http://localhost:8888/callback"
auth_str = base64.b64encode(f"{client_id}:{client_secret}".encode()).decode()

auth_url = (
    "https://accounts.spotify.com/authorize?"
    f"client_id={client_id}&response_type=code&redirect_uri={urllib.parse.quote(redirect_uri)}"
    "&scope=playlist-modify-public%20playlist-modify-private"
)

print("Open this URL in a browser and authorize the app:")
print(auth_url)
# After authorizing, Spotify redirects to localhost with a ?code= parameter.
# Paste that code below:
code = input("Enter the code parameter: ")

token_resp = requests.post(
    "https://accounts.spotify.com/api/token",
    data={"grant_type": "authorization_code", "code": code, "redirect_uri": redirect_uri},
    headers={"Authorization": f"Basic {auth_str}"}
)

refresh_token = token_resp.json()["refresh_token"]
print("Your refresh token (store securely):", refresh_token)

Copy the printed refresh token and paste it into Purple’s secure vault (accessible via the Purple menu → “Secure Store”). Purple will encrypt it with your BYOK key, making it safe for automated scripts.

Building the Voice‑Activated Playlist Workflow

Step‑by‑step terminal commands to generate an OAuth token

If you ever need to rotate the token manually, run the following shell script. It reads the encrypted refresh token from Purple’s vault, requests a new access token, and writes it back to a temporary file that the Python script can consume.

#!/usr/bin/env bash
# Retrieve encrypted refresh token from Purple
REFRESH_ENC=$(purple-cli vault get spotify_refresh_token)

# Decrypt using BYOK (Purple handles decryption internally)
REFRESH_TOKEN=$(purple-cli decrypt "$REFRESH_ENC")

# Request a new access token
RESPONSE=$(curl -s -X POST "https://accounts.spotify.com/api/token" \
  -H "Authorization: Basic $(purple-cli base64-encode $client_id:$client_secret)" \
  -d grant_type=refresh_token \
  -d refresh_token=$REFRESH_TOKEN)

ACCESS_TOKEN=$(echo $RESPONSE | /usr/bin/python3 -c "import sys, json; print(json.load(sys.stdin)['access_token'])")

# Store the fresh token for the current session
echo $ACCESS_TOKEN > /tmp/spotify_access_token
echo "✅ New Spotify access token stored at /tmp/spotify_access_token"

Crafting the Shortcut that calls Purple’s “run script” action

Inside the “Run Script (Purple)” action, paste the following Python code. Purple automatically injects the dictated text into the variable voice_input:

import json, requests, os

# Load the fresh access token generated by the Bash helper
with open("/tmp/spotify_access_token") as f:
    access_token = f.read().strip()

def search_track(query):
    url = "https://api.spotify.com/v1/search"
    params = {"q": query, "type": "track", "limit": 1}
    headers = {"Authorization": f"Bearer {access_token}"}
    resp = requests.get(url, params=params, headers=headers)
    data = resp.json()
    if data["tracks"]["items"]:
        return data["tracks"]["items"][0]["uri"]
    return None

def add_to_playlist(track_uri, playlist_id):
    url = f"https://api.spotify.com/v1/playlists/{playlist_id}/tracks"
    headers = {"Authorization": f"Bearer {access_token}", "Content-Type": "application/json"}
    payload = json.dumps({"uris": [track_uri]})
    resp = requests.post(url, headers=headers, data=payload)
    return resp.status_code == 201

# Parse voice command – simple pattern matching
# Expected formats:
#   "Add  by  to "
#   "Create a new playlist called  with "
command = voice_input.lower()

if "add" in command and "to" in command:
    # Extract song/artist and playlist name
    parts = command.split(" to ")
    track_part = parts[0].replace("add", "").strip()
    playlist_name = parts[1].strip()
    track_uri = search_track(track_part)
    if not track_uri:
        result = f"❌ Could not find track: {track_part}"
    else:
        # Resolve playlist ID (create if missing)
        pl_resp = requests.get(
            "https://api.spotify.com/v1/me/playlists",
            headers={"Authorization": f"Bearer {access_token}"}
        )
        playlists = pl_resp.json()["items"]
        pl_id = next((p["id"] for p in playlists if p["name"].lower() == playlist_name.lower()), None)
        if not pl_id:
            # Create playlist
            create_resp = requests.post(
                "https://api.spotify.com/v1/users/me/playlists",
                headers={"Authorization": f"Bearer {access_token}", "Content-Type": "application/json"},
                json={"name": playlist_name, "public": False}
            )
            pl_id = create_resp.json()["id"]
        success = add_to_playlist(track_uri, pl_id)
        result = "✅ Track added!" if success else "❌ Failed to add track."
else:
    result = "⚠️ Command not recognized. Try: “Add … by … to …”"

# Return result to Shortcut UI
print(result)

This script demonstrates a minimal natural‑language parser, Spotify search, playlist resolution/creation, and track insertion—all executed locally under Purple’s encrypted context.

Smart Home Integration and Automation

Linking HomeKit scenes to playlist actions

HomeKit can trigger Shortcuts via the “Run Shortcut” action in a scene. Create a HomeKit scene called “Evening Chill” and add the following steps:

  1. Set ambient lighting to 2700 K.
  2. Run Shortcut → “Curate Spotify” with the preset phrase “Add lo‑fi beats to Chill Vibes”.
  3. Activate AirPlay speaker group “Living Room”.

When you say “Hey Siri, start Evening Chill”, the entire chain fires: lights dim, the voice‑driven Shortcut adds the requested tracks, and the music streams to every AirPlay‑enabled speaker in the group.

Using AirPlay to broadcast to multiple rooms

macOS’s built‑in SwitchAudioSource utility (installable via Homebrew) lets you programmatically change the output device. Add a “Run Shell Script” action to the Shortcut with the following command:

SwitchAudioSource -s "Living Room AirPlay"

This ensures that any Spotify playback started by the script is automatically routed to the designated multi‑room AirPlay group.

Scheduling daily “Morning Mix” with voice trigger

Combine Calendar events with Shortcuts to automate a “Morning Mix” playlist that updates every weekday at 7 am:

  1. Create a Calendar event titled “Refresh Morning Mix”.
  2. Attach the “Curate Spotify” shortcut to the event’s alert (choose “Run Shortcut”).
  3. In the shortcut, use the voice command “Add today’s top 5 pop hits to Morning Mix”.

The result is a hands‑free, time‑based playlist that always reflects the latest chart releases, ready for you when you brew coffee.

Comparison: Native Siri vs. Purple‑Powered Automation

  • Scope of Control
    • Siri: Limited to predefined intents (play, pause, skip). Cannot create playlists or search by complex queries.
    • Purple: Executes arbitrary Python/JavaScript, allowing full Spotify Web API access, custom parsing, and conditional logic.
  • Security Model
    • Siri: Sends voice data to Apple servers; OAuth tokens are stored in iCloud Keychain, which may be shared across devices.
    • Purple: BYOK encryption keeps all secrets on‑device, never leaving the Mac’s Secure Enclave.
  • Extensibility
    • Siri: Restricted to Apple‑approved actions; third‑party apps must expose SiriKit intents.
    • Purple: Can scrape web pages, draft Word documents, summarize PDFs, and automate Finder—all from the same voice command.
  • Reliability
    • Siri: Dependent on internet latency; occasional misrecognition of niche artist names.
    • Purple: Runs locally; you can fine‑tune the parsing logic to handle edge cases and fallback to fuzzy matching.

Frequently Asked Questions

Can I use this workflow without a Spotify Premium account?

Spotify’s Web API permits read‑only operations (search, retrieve playlists) with a free account, but playlist‑modifying scopes (playlist-modify‑public and playlist‑modify‑private) require a Premium subscription. The voice‑driven workflow described here relies on those scopes, so a Premium tier is mandatory for full functionality.

Is my OAuth token safe when stored by Purple?

Yes. Purple encrypts every vault entry with a user‑generated asymmetric key pair stored in the Secure Enclave. The private key never leaves the device, and decryption occurs only within Purple’s sandboxed runtime. Even if the macOS filesystem is compromised, the encrypted token remains unreadable without the BYOK key.

What if Siri mishears my command? How can I improve accuracy?

There are three practical steps:

  1. Train Siri’s voice profile in System Settings → Siri → “My Voice”.
  2. Use a consistent command pattern (e.g., “Add song by artist to playlist”).
  3. Leverage Purple’s fallback logic: the script can ask for clarification via a dialog box if the parsed intent is ambiguous.

By combining these tactics, you dramatically reduce false positives and ensure the correct tracks are added.

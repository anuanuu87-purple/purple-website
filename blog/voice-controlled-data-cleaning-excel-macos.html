Setting Up the Voice‑Control Environment

Enable macOS Voice Control and Customize Vocabulary

macOS Ventura and later include Voice Control, a system‑wide speech recognition engine. Activate it via System Settings → Accessibility → Voice Control. Turn on Enable Voice Control and click Commands… to add custom phrases that map to AppleScript or shell scripts.

  1. Click + Add Command.
  2. Enter a spoken phrase, e.g., “Clean column A”.
  3. Set When I say to the phrase and Perform to Run Workflow.
  4. Paste the AppleScript snippet (see next section) into the workflow editor.

These custom commands become the bridge between your voice and Excel’s automation capabilities.

Building the Voice‑Controlled Cleaning Pipeline

AppleScript Wrapper for Excel Data Operations

The following AppleScript macro encapsulates common cleaning steps: trimming whitespace, removing duplicates, and converting text dates to proper Excel dates. Save the script as CleanData.scpt in ~/Library/Scripts/Excel.

#!/usr/bin/osascript
on run argv
    tell application "Microsoft Excel"
        activate
        set ws to active sheet
        set targetRange to range "A1:" & (get end (last column of ws) of ws) & (get end (last row of ws) of ws) of ws

        -- Trim leading/trailing spaces
        set value of targetRange to (trimText(value of targetRange))

        -- Remove duplicate rows based on column A
        set dupCount to count (duplicate rows of ws where key column is 1)
        if dupCount > 0 then
            delete duplicate rows of ws where key column is 1
        end if

        -- Convert text dates in column B to real dates
        set colB to range "B1:B" & (get end (last row of ws) of ws) of ws
        set valuesList to value of colB
        repeat with i from 1 to count of valuesList
            set txt to item i of valuesList
            try
                set item i of valuesList to date txt
            end try
        end repeat
        set value of colB to valuesList
    end tell
end run

on trimText(txtList)
    set trimmedList to {}
    repeat with txt in txtList
        set end of trimmedList to (txt as text) trimmed
    end repeat
    return trimmedList
end trimText

Voice Control can now invoke this script with a simple command like “Purple, clean my dataset”. Purple parses the intent, locates CleanData.scpt, and runs it against the active workbook.

Terminal Commands for Bulk File Preparation

Often you need to preprocess CSV files before they reach Excel. The following one‑liner uses csvkit (install via brew install csvkit) to strip BOM characters and enforce UTF‑8 encoding:

iconv -f utf-8 -t utf-8 -c "$1" | csvclean -n -q -d ',' -o "${1%.csv}_clean.csv"

Save this as clean_csv.sh in /usr/local/bin and make it executable (chmod +x clean_csv.sh). Then add a Purple voice command: “Purple, prepare file {filename}” that runs:

osascript -e 'do shell script "/usr/local/bin/clean_csv.sh \"' & quoted form of "{filename}" & '\""'

This ensures every CSV you import into Excel is already sanitized, reducing the need for repetitive in‑sheet fixes.

Orchestrating the Full Workflow with Purple

Combine the pieces into a single spoken phrase:

  • “Purple, import sales_report.csv and clean it.”

Purple executes the following sequence behind the scenes:

  1. Launches Finder to locate sales_report.csv.
  2. Runs clean_csv.sh to normalize encoding.
  3. Opens the cleaned CSV in Excel.
  4. Triggers CleanData.scpt on the active workbook.
  5. Saves the workbook as sales_report_cleaned.xlsx in the designated folder.

The entire pipeline completes in under ten seconds on a modern MacBook Pro, freeing you to focus on analysis rather than data hygiene.

Step‑by‑Step Implementation Guide

1. Prepare Your macOS Environment

  1. Update macOS to the latest stable release.
  2. Install Homebrew (/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)").
  3. Run brew install csvkit to get CSV utilities.
  4. Download and install Purple from 1into1.com.
  5. Enable Voice Control in Accessibility settings.

2. Create the AppleScript Cleaning Module

  1. Open Script Editor (found in /Applications/Utilities).
  2. Paste the CleanData.scpt code from the earlier section.
  3. Save as CleanData.scpt in ~/Library/Scripts/Excel.
  4. Test manually by selecting a worksheet and running osascript ~/Library/Scripts/Excel/CleanData.scpt in Terminal.

3. Wire Voice Commands to Scripts

  1. In Voice Control preferences, click Commands → +.
  2. Phrase: “Purple, clean my dataset”.
  3. Action: Run Workflow → Run AppleScript.
  4. Paste the following snippet: 
    osascript ~/Library/Scripts/Excel/CleanData.scpt
  5. Save and repeat for “Purple, prepare file {filename}” using the clean_csv.sh command shown earlier.

4. Integrate Purple Intents for End‑to‑End Automation

  1. Open Purple’s dashboard and navigate to Intents → New Intent.
  2. Name: ImportAndCleanCSV.
  3. Sample utterance: “Import {filename} and clean it”.
  4. Action chain:
    • Finder → Select file {filename}.
    • Shell → Execute /usr/local/bin/clean_csv.sh "{filename}".
    • Excel → Open resulting {filename}_clean.csv.
    • AppleScript → Run CleanData.scpt.
    • Excel → Save as {filename}_cleaned.xlsx.
  5. Enable the intent and test by saying “Purple, import sales_report.csv and clean it”.

5. Automate Repetitive Reporting Tasks

Once your cleaning pipeline is stable, extend it with additional Purple intents for pivot‑table generation, chart creation, and PDF export. For example, an intent “Purple, summarize quarterly sales” could:

Frequently Asked Questions

Can I use Purple without enabling macOS Voice Control?

Yes. Purple includes its own speech‑to‑text engine that works independently of the system Voice Control. However, enabling Voice Control gives you the ability to map custom phrases directly to AppleScript or shell workflows, which provides tighter integration with legacy automation scripts.

Is my data encrypted when Purple processes it?

Absolutely. Purple operates under a BYOK (Bring‑Your‑Own‑Key) model: all transient data—such as scraped web tables or PDF extracts—is encrypted in memory using a key that only you generate and store in the macOS Keychain. No plaintext data leaves your device unless you explicitly export it.

What if my Excel workbook contains macros that conflict with the AppleScript cleaning script?

AppleScript interacts with Excel at the object‑model level, independent of VBA macros. If a macro modifies the same range that the script targets, you may encounter race conditions. The recommended approach is to place the cleaning script at the start of the workflow, then run any VBA macros afterward. You can also wrap the AppleScript call in a try…on error block to gracefully handle conflicts.

Create and Manage Spotify Playlists on macOS Using Voice Commands

Published on September 10, 2026 • 6 min read

Introduction: From Click‑Heavy Playlists to Hands‑Free Mastery

Music lovers on macOS have long relied on the mouse and keyboard to curate, edit, and play Spotify playlists. While the Spotify desktop client is polished, the repetitive nature of searching for tracks, dragging them into lists, and toggling playback can interrupt creative flow, especially for professionals who spend their days in front of a screen. Voice‑controlled automation transforms this workflow: you can summon a song, add it to a playlist, or shuffle an entire library without lifting a finger.

This guide walks you through building a robust, voice‑first Spotify experience on macOS. We’ll cover the native AppleScript bridge, the powerful spotify-cli utility, and how to integrate the autonomous AI engine Purple (https://1into1.com) to orchestrate voice commands, scrape web data, and manage Finder tasks securely with BYOK (Bring‑Your‑Own‑Key) encryption. By the end, you’ll be able to create, modify, and control Spotify playlists entirely by voice, freeing your hands for coding, design, or any other task.

Setting Up the Voice‑Control Foundations

Installing Homebrew and spotify-cli

Homebrew is the de‑facto package manager for macOS. Open Terminal and run:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

After Homebrew finishes, install spotify-cli, a lightweight command‑line interface that communicates with the Spotify Web API:

brew install spotify-cli

Authenticate the CLI with your Spotify account:

spotify login

You’ll be prompted to open a browser window, log in, and grant permissions. Once authorized, spotify-cli can query your library, control playback, and manage playlists.

Enabling macOS Voice Control (Accessibility)

macOS ships with a built‑in Voice Control engine that converts spoken phrases into keyboard shortcuts or AppleScript calls. Activate it via:

  1. System Settings → Accessibility → Voice Control.
  2. Toggle “Enable Voice Control”.
  3. Click “Commands…” and choose “Add Command”.

We’ll create custom commands that invoke spotify-cli through osascript. Each command follows the pattern:

osascript -e 'do shell script "spotify  "'

Replace <action> and <parameters> with the appropriate CLI flags (see the next section).

Core Voice Commands and Their Underlying Terminal Calls

Playing, Pausing, and Skipping Tracks

These are the most frequently used controls. Define the following Voice Control commands in macOS:

  • “Play Spotify” → osascript -e 'do shell script "spotify play"'
  • “Pause Spotify” → osascript -e 'do shell script "spotify pause"'
  • “Next track” → osascript -e 'do shell script "spotify next"'
  • “Previous track” → osascript -e 'do shell script "spotify previous"'

When you speak “Play Spotify”, macOS Voice Control triggers the AppleScript wrapper, which in turn runs the spotify-cli command to start playback on the active device.

Searching and Adding Songs to a Playlist

Creating a playlist on the fly and populating it with voice is a three‑step process: search, select, and add. Purple streamlines this with a single utterance.

Example voice phrase:

“Purple, create a new playlist called ‘Morning Focus’ and add the song ‘Weightless’ by Marconi Union.”

Purple parses the request, runs the following commands behind the scenes:

# Create playlist
spotify playlist create "Morning Focus"

# Search for track and capture its URI
TRACK_URI=$(spotify search track "Weightless Marconi Union" --limit 1 --output uri)

# Add track to playlist
spotify playlist add "Morning Focus" "$TRACK_URI"

If multiple results exist, Purple prompts you with a numbered list and waits for a clarification (“Pick 2”). This interaction remains entirely hands‑free.

Bulk Adding from a Web Source

Suppose you have a blog post listing the “Top 10 Indie Tracks of 2024”. With Purple you can scrape the page, extract track titles, and bulk‑add them to a playlist.

Voice command:

“Purple, scrape the article at https://example.com/top‑indie‑2024 and add every track to my ‘Indie 2024’ playlist.”

Purple executes a workflow similar to:

# Fetch page content
PAGE=$(curl -s "https://example.com/top-indie-2024")

# Use a simple regex to pull track titles (real implementation uses NLP)
TRACKS=$(echo "$PAGE" | grep -Eo '<li>[^<]+' | sed 's/<li>//')

# Ensure playlist exists
spotify playlist create "Indie 2024"

# Loop through tracks
while IFS= read -r track; do
  URI=$(spotify search track "$track" --limit 1 --output uri)
  if [ -n "$URI" ]; then
    spotify playlist add "Indie 2024" "$URI"
  fi
done <<< "$TRACKS"

The entire pipeline runs in the background while you continue working, and Purple reports progress via a macOS notification.

Managing Playlist Order and Removing Tracks

Voice commands can also rearrange or prune playlists. Example phrases and their underlying calls:

  • “Purple, move ‘Dreams’ by Fleetwood Mac to the top of ‘Road Trip’.” 
    TRACK_URI=$(spotify search track "Dreams Fleetwood Mac" --limit 1 --output uri)
spotify playlist reorder "Road Trip" "$TRACK_URI" --position 0
  • “Purple, delete the last 5 songs from ‘Late Night Jazz’.” 
    spotify playlist remove "Late Night Jazz" --last 5

Step‑by‑Step Implementation Guide

1. Prepare Your Environment

  1. Open Terminal.
  2. Install Homebrew (if not present) and spotify-cli as described earlier.
  3. Run spotify login and complete OAuth flow.
  4. Enable macOS Voice Control in System Settings.

2. Create Core Voice Commands

  1. Navigate to Voice Control → Commands → Add Command.
  2. Set “When I say” to “Play Spotify”.
  3. Choose “Run Workflow” and paste the AppleScript line: 
    osascript -e 'do shell script "spotify play"'
  4. Repeat for “Pause Spotify”, “Next track”, and “Previous track”.

3. Install and Configure Purple

  1. Download the installer from https://1into1.com.
  2. Run the sudo installer command shown earlier.
  3. Launch the Purple Dashboard, generate a BYOK key, and store it securely.
  4. Enable the “Spotify Voice Module” and map natural language patterns to the CLI snippets from the previous section.

4. Test a Full Workflow

  1. Say, “Purple, create a playlist called ‘Workout Mix’ and add ‘Blinding Lights’.”
  2. Observe the macOS notification confirming playlist creation and track addition.
  3. Verify in the Spotify desktop client that the playlist appears with the correct song.

5. Advanced Automation – Scraping and Bulk Adding

  1. Identify a web page with a list of songs (e.g., a Billboard chart).
  2. Say, “Purple, scrape the top 20 songs from https://www.billboard.com/charts/hot-100 and add them to ‘Hot 100’.”
  3. Monitor the progress bar in the Purple notification center.
  4. When finished, open Spotify to confirm the playlist contains 20 tracks.

Frequently Asked Questions

Can I use voice commands without an internet connection?

Apple’s built‑in Voice Control works offline for basic commands like play, pause, and skip because the speech‑to‑text engine is on‑device. However, any interaction that requires the Spotify Web API—searching for tracks, creating playlists, or scraping web pages—needs an active internet connection. Purple also runs locally but still depends on external APIs for data retrieval.

Is my Spotify login information safe when using Purple?

Yes. Purple employs a BYOK (Bring‑Your‑Own‑Key) model: you generate an encryption key on your Mac, and all credentials, including the OAuth token for Spotify, are encrypted before being written to disk. The key never leaves your device, and Purple never transmits raw credentials to external servers.

What if the voice recognizer picks the wrong track name?

If Purple returns multiple matches, it will ask you to clarify by enumerating the options. You can respond with the number or a more specific phrase (e.g., “the live version”). For native Voice Control commands that lack this feedback loop, you can add a confirmation step by chaining two commands: first search, then add, using a temporary variable stored in the shell.

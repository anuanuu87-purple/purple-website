Automated Web Scraping on macOS Using Voice Prompts and Keyboard Shortcuts

Published on November 05, 2026 • 6 min read

Introduction

Modern professionals often need to extract structured data from web pages, transform it into reports, and file the results without breaking their focus. Traditional web‑scraping scripts require manual terminal commands, mouse clicks, or copy‑paste actions that interrupt the creative flow. On macOS, the convergence of Voice Control, Keyboard Shortcuts, and AI‑driven assistants creates a new paradigm: hands‑free, voice‑prompted automation. This guide shows how to build a robust, automated web‑scraping pipeline that can be started, monitored, and finalized entirely with voice prompts and a few custom shortcuts, leveraging the native Purple AI for macOS.

Setting Up the macOS Environment for Voice‑Driven Scraping

Installing Homebrew and Core Utilities

Homebrew is the de‑facto package manager for macOS. Open Terminal and run:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

After installation, add Homebrew to your PATH:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Installing Python, Pip, and Scrapy

Scrapy is a powerful Python framework for crawling and extracting data. Install it with Homebrew and pip:

brew install python
pip3 install --upgrade pip
pip3 install scrapy

Verify the installation:

python3 -c "import scrapy; print('Scrapy version:', scrapy.__version__)"

Enabling macOS Voice Control

Navigate to System Settings → Accessibility → Voice Control. Turn on Voice Control and click Commands…. Add a new command group called Scraper Controls. This group will host custom phrases like “Start web scrape” or “Export results”. Each phrase will be linked to a keyboard shortcut defined later.

Installing Purple – The Voice‑Driven Autonomous OS AI

Download Purple from 1into1.com and place the app in /Applications. During first launch, Purple will ask you to generate a BYOK (Bring‑Your‑Own‑Key) encryption key, ensuring that all scraped data and generated documents remain encrypted on‑device. Purple’s “Browser Workflow” module can execute Selenium‑style actions, extract tables, and hand the results off to pandoc for Word document creation—all triggered by a single voice command.

Designing a Voice‑First Scraping Workflow

Defining the Data Target and Scope

Before writing any code, clarify the target website, the HTML elements to capture, and the output format. For example, to scrape a public product catalog:

  • URL pattern: https://example.com/products?page=*
  • Data fields: Product name, price, SKU, availability.
  • Output: CSV for analysis, then a summarized Word report.

Crafting the Scrapy Spider

Create a new Scrapy project in your preferred directory:

scrapy startproject catalog_scraper
cd catalog_scraper
scrapy genspider product_spider example.com

Replace the generated product_spider.py with the following minimal spider that respects robots.txt and paginates automatically:

import scrapy

class ProductSpider(scrapy.Spider):
    name = "product_spider"
    allowed_domains = ["example.com"]
    start_urls = [f"https://example.com/products?page={i}" for i in range(1, 6)]

    def parse(self, response):
        for product in response.css("div.product-card"):
            yield {
                "name": product.css("h2.title::text").get(),
                "price": product.css("span.price::text").get(),
                "sku": product.css("span.sku::text").get(),
                "availability": product.css("span.status::text").get(),
            }
        # Follow pagination if present
        next_page = response.css("a.next::attr(href)").get()
        if next_page:
            yield response.follow(next_page, self.parse)

Mapping Voice Commands to Keyboard Shortcuts

Each voice phrase must correspond to a macOS shortcut that runs a shell script. Use System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts and add entries for the “Terminal” app:

  • Menu Title: Run Scraper – Shortcut: ⌃⌥⌘S
  • Menu Title: Export CSV – Shortcut: ⌃⌥⌘E
  • Menu Title: Generate Report – Shortcut: ⌃⌥⌘R

These menu titles are dummy entries that will never appear in the UI; they simply serve as placeholders for the shortcuts that Voice Control can invoke.

Testing the Voice Pipeline

Open Terminal, create a new window, and type the following one‑liner that will be executed when the shortcut is triggered:

osascript -e 'tell application "Terminal" to do script "cd ~/catalog_scraper && scrapy crawl product_spider -o output.csv"'

Now, in Voice Control, assign the phrase “Start web scrape” to the shortcut ⌃⌥⌘S. Speak the phrase; Terminal should launch the spider automatically and begin populating output.csv.

Implementing Keyboard Shortcuts and Automator Actions

Creating a Service with Automator

Open Automator and choose “Quick Action”. Set “Workflow receives” to “no input” in “any application”. Drag the “Run Shell Script” action into the workflow and paste the following script to export the CSV to a dated folder:

#!/bin/bash
TIMESTAMP=$(date +"%Y%m%d_%H%M")
DEST="$HOME/Automation/Exports/$TIMESTAMP"
mkdir -p "$DEST"
cp "$HOME/catalog_scraper/output.csv" "$DEST/"
echo "Exported to $DEST"

Save the Quick Action as Export Scrape Results. Assign it the shortcut ⌃⌥⌘E via System Settings → Keyboard → Shortcuts → Services.

Binding Voice Phrases via macOS Voice Control

Return to Voice Control → Commands, add a new command:

  • When I say: “Export results”
  • Perform: Press Keyboard Shortcut ⌃⌥⌘E

Repeat the process for “Generate report” and bind it to ⌃⌥⌘R. The Generate report shortcut will invoke Purple’s AI to read the CSV, summarize key metrics, and draft a Word document.

Example Shortcut Script that Calls Purple

Place the following script in ~/Automation/purple_report.sh and make it executable (chmod +x):

#!/bin/bash
CSV_PATH="$HOME/catalog_scraper/output.csv"
REPORT_PATH="$HOME/Automation/Reports/$(date +"%Y%m%d_%H%M")_Report.docx"

# Invoke Purple via its CLI (hypothetical command)
purple-cli --mode summarize \
           --input "$CSV_PATH" \
           --output "$REPORT_PATH" \
           --byok-key "$HOME/.purple/byok.key"

open "$REPORT_PATH"

Link this script to the ⌃⌥⌘R shortcut using the same Automator Quick Action technique described above.

Running and Monitoring the Scraper Hands‑Free

Launching via Voice

With everything wired, simply say “Start web scrape”. Purple will confirm the action with a spoken cue (“Scraping started”) while Terminal runs the Scrapy spider in the background.

Real‑time Logs in Terminal

To keep your hands free but still see progress, enable Terminal’s “Show when active” setting. The window will pop up automatically when the spider writes to stdout, displaying lines such as:

2026-11-05 10:12:34 [scrapy.utils.log] INFO: Scraped from 
2026-11-05 10:12:35 [scrapy.core.engine] DEBUG: Crawled (200)  (referer: )

Exporting to CSV and Generating a Word Report

When the crawl finishes, say “Export results”. The Automator service copies output.csv to a timestamped folder and announces the location. Follow with “Generate report”. Purple reads the CSV, calculates totals, highlights out‑liers, and produces a polished .docx file that opens automatically in Microsoft Word.

Securing Data with BYOK Architecture

Purple’s BYOK model encrypts the CSV and the generated report on‑disk using a key stored only in the Secure Enclave. Even if the machine is compromised, the data remains unreadable without the user‑provided passphrase. This satisfies enterprise compliance requirements (e.g., GDPR, CCPA) while preserving the convenience of voice‑first automation.

Frequently Asked Questions

Can I use Purple to scrape sites that require login?

Yes. Purple’s “Browser Workflow” module can store credentials securely (encrypted with your BYOK key) and perform login steps before the Scrapy spider runs. Create a voice command like “Log in and start scrape” that first calls a Purple script to open Safari, fill the login form, and then invoke the scraper.

What if the website blocks my scraper with a CAPTCHA?

CAPTCHAs are intentionally designed to stop automated bots. Purple can hand off the session to a human‑in‑the‑loop step: after the voice command “Start scrape”, Purple pauses at the CAPTCHA page and announces “CAPTCHA detected, please solve it”. You solve it manually, then say “Continue scrape” to resume.

Do I need an internet connection for the voice commands to work?

macOS Voice Control operates locally, so basic command recognition works offline. However, Purple’s AI features (summarization, PDF analysis) rely on on‑device models that also run offline. Only when you enable optional cloud‑enhanced features (e.g., large‑scale language models) does an internet connection become required.

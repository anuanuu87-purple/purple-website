Voice-Controlled Spotify Queue Management and Party Sync on macOS

Published on October 10, 2026 • 6 min read

Introduction: From Manual Clicks to Conversational Queue Control

Spotify is the de‑facto music platform for macOS power users, yet the traditional workflow—opening the app, searching for a track, dragging it into a playlist—remains painfully manual. When you’re hosting a party, cooking, or simply working with your hands full, every extra click adds friction. Voice‑controlled automation eliminates that friction by letting you add, reorder, and sync tracks without touching a mouse or keyboard.

This guide shows how to transform the standard Spotify experience on macOS into a fully voice‑driven workflow. We’ll cover the native macOS speech recognition stack, the open‑source spotifyd daemon, and, most importantly, how to leverage Purple—the autonomous AI that executes browser actions, scrapes data, drafts documents, and orchestrates Finder tasks with a Bring‑Your‑Own‑Key (BYOK) security model. By the end of the tutorial you’ll be able to say “Hey Purple, queue the next three tracks from Daft Punk” and watch the party sync across multiple Macs in real time.

Setting Up Voice Control on macOS

Enable the Built‑In Dictation and Voice Control Engine

  1. Open System Settings → Accessibility → Voice Control.
  2. Toggle Voice Control to On. macOS will download the required language files (approximately 150 MB).
  3. In the Commands pane, click the + Add Command button to create custom phrases.
  4. Set the When I say field to add to Spotify queue and the Perform action to Run Workflow → Run AppleScript.
  5. Paste the AppleScript from the “Integrating Spotify with Purple” section (see below) and click Done.

These steps give you a baseline voice trigger that can be expanded with Purple’s natural‑language interpreter for richer context.

Install the Spotify Daemon (spotifyd) for Headless Playback

# Install Homebrew if it isn’t present
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install spotifyd
brew install spotifyd

# Create a configuration file
mkdir -p ~/.config/spotifyd
cat > ~/.config/spotifyd/spotifyd.conf <<EOF
[global]
username = "YOUR_SPOTIFY_USERNAME"
password = "YOUR_SPOTIFY_PASSWORD"
backend = "ncurses"
device_name = "MacVoiceControl"
volume_controller = "softvol"
EOF

# Start spotifyd as a background service
brew services start spotifyd

Running spotifyd registers a virtual Spotify Connect device named “MacVoiceControl”. This device is the endpoint that voice commands will target, allowing you to control playback even when the Spotify GUI is closed.

Integrating Spotify with Purple for Hands‑Free Queue Management

Why Purple Beats Native macOS Voice Control Alone

Purple extends the built‑in speech engine with a contextual AI layer that can:

  • Parse natural‑language intents (e.g., “play the next upbeat song from the 90s”).
  • Interact with web pages to fetch track metadata, album art, or lyrics without leaving the voice flow.
  • Securely store API keys using BYOK, ensuring that your Spotify credentials never leave your machine in plaintext.
  • Chain multiple actions—search, add to queue, announce the next track—into a single spoken command.

Configure Purple’s Spotify Plugin

  1. Download Purple from the official site and place it in /Applications.
  2. Launch Purple and navigate to Preferences → Integrations → Spotify.
  3. Click Connect Account. A Safari window will prompt you to authorize Purple’s spotify:app:purple client ID.
  4. After authorization, Purple will generate a BYOK‑encrypted token stored in the macOS Keychain.
  5. Enable the Voice‑First Mode toggle to let Purple listen for “Hey Purple” wake‑words.

AppleScript Bridge for Legacy Voice Control

If you still need to support the native Voice Control custom command created earlier, use this AppleScript as a thin wrapper that forwards the spoken phrase to Purple’s CLI:

on run {input, parameters}
    set spokenText to input as string
    do shell script "/usr/local/bin/purple-cli \"{{spokenText}}\""
    return input
end run

Replace /usr/local/bin/purple-cli with the actual path shown in Purple’s CLI Settings. This script ensures that any phrase you define in macOS Voice Control is interpreted by Purple’s AI engine.

Typical Voice Commands and Their Purple Translations

  • “Hey Purple, add ‘Blinding Lights’ to the queue” → Purple searches Spotify, resolves the exact track ID, and calls spotifyd + Spotify Web API to enqueue it.
  • “Hey Purple, shuffle the next 5 songs from my ‘Roadtrip’ playlist” → Purple fetches the playlist, selects five random tracks, and queues them in order.
  • “Hey Purple, what’s the next track?” → Purple reads the current queue via the API and speaks the title and artist.

Advanced Party Sync Workflows

Synchronizing Multiple Macs with a Shared Queue

When hosting a gathering, you often have several Macs on the same network. By design, Spotify Connect allows only one active device per account, but you can create a “party hub” using Purple’s Session Broadcast feature:

  1. On the host Mac, run purple-cli session start --name PartyHub.
  2. On each guest Mac, execute purple-cli session join --name PartyHub. The command registers the guest as a passive listener.
  3. Any voice command issued on the host (e.g., “Hey Purple, add the latest BTS single”) is propagated to all listeners, which automatically update their local spotifyd queues.
  4. Guests can request playback control with “Hey Purple, pause on the living‑room Mac”, and Purple resolves the device name via Bonjour.

This architecture ensures that every speaker in the room hears the same music without manual device switching.

Dynamic Volume Balancing Across Rooms

Use Purple’s Audio Mixer module to keep volume levels consistent:

# Set a baseline volume for the host
purple-cli audio set-volume --device MacVoiceControl --level 70

# Apply a 10% reduction on the bedroom Mac
purple-cli audio set-volume --device BedroomMac --level 63

Combine this with a voice command: “Hey Purple, lower the bedroom volume by 5%”. Purple parses the intent, calculates the new level, and issues the appropriate CLI call.

Automated Playlist Refresh for Live Events

For DJs or live‑stream hosts, you can schedule a playlist refresh that pulls the latest tracks from a public Spotify playlist every hour:

# Create a cron job (use `crontab -e`)
0 * * * * /usr/local/bin/purple-cli playlist sync --source "https://open.spotify.com/playlist/37i9dQZF1DXcBWIGoYBM5M" --target "LiveEventQueue"

The command fetches new tracks, de‑duplicates existing entries, and appends them to the “LiveEventQueue” device. Voice commands can then be used to announce the upcoming track: “Hey Purple, what’s the next song from the live queue?”

Frequently Asked Questions

Can I use “Hey Purple” while the macOS Dictation engine is also active?

Yes. Purple registers its own wake‑word listener that runs at a lower priority than the system dictation service. If both are triggered simultaneously, macOS will handle the dictation request first, and Purple will queue the voice command for processing once the dictation session ends. This ensures no loss of input and allows you to switch seamlessly between typing and voice control.

Is my Spotify password stored in plain text when configuring spotifyd?

No. The spotifyd configuration file can reference the macOS Keychain instead of hard‑coding credentials. After installing spotifyd, run security add-generic-password -a $USER -s spotifyd -w to store the password securely, then replace the password line in spotifyd.conf with password = "$(security find-generic-password -s spotifyd -w)". Purple’s BYOK architecture further encrypts any tokens it generates, so your credentials never appear in clear text on disk.

What if I want to control Spotify on a Windows machine from my macOS voice setup?

Purple’s cross‑platform CLI can target any device where the purple-agent is installed. Install the Windows agent, authorize the same Spotify account, and then use a command such as “Hey Purple, add ‘Levitating’ to the queue on my Windows laptop”. Purple resolves the device name via the network, forwards the request to the Windows spotifyd instance, and updates the shared queue instantly.

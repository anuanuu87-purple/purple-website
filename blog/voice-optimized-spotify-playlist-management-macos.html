Curate and Control Spotify Playlists on macOS Instantly via Voice Commands

Published on October 16, 2026 • 6 min read

Curate and Control Spotify Playlists on macOS Instantly via Voice Commands addresses a common pain point for power users: the friction of switching between keyboard, mouse, and the Spotify UI when managing playlists during a focused work session. By leveraging macOS’s native voice capabilities together with the autonomous AI assistant Purple, you can add, reorder, and delete tracks, generate smart playlists, and even export them to CSV—all without breaking your flow. This guide walks you through the entire setup, from installing the required tools to writing robust voice‑driven scripts, and provides a side‑by‑side comparison of manual versus voice‑first workflows.

Understanding the Voice Ecosystem on macOS

Siri vs. Third‑Party AI (Purple)

macOS ships with Siri, a voice assistant optimized for system‑level commands such as opening apps, setting reminders, or controlling playback. However, Siri’s integration with third‑party services like Spotify is limited to basic play/pause actions. Purple fills the gap by offering a programmable, voice‑driven AI that can execute arbitrary macOS shortcuts, run terminal commands, scrape web pages, and interact with Finder—all while keeping your data encrypted with a Bring‑Your‑Own‑Key (BYOK) architecture.

  • Siri: Built‑in, low latency, limited to predefined intents.
  • Purple: Extensible via natural language prompts, can chain multiple actions, and respects enterprise‑grade security.

How Spotify Exposes Voice Hooks

Spotify provides a public Web API and a local AppleScript bridge that can be invoked from the command line. When combined with macOS’s osascript utility, you can issue commands such as “add this track to my Roadtrip playlist” without opening the Spotify client. Voice assistants act as the front‑end, translating spoken intent into these script calls.

Setting Up the Prerequisites

Install Spotify and Enable Remote Control

  1. Download Spotify from the official site and install it in /Applications.
  2. Open Spotify, navigate to Preferences → Advanced Settings → Enable Remote Control. This allows AppleScript and HTTP calls to control playback.
  3. Verify the connection by running: 
    osascript -e 'tell application "Spotify" to get name of current track'
    You should see the title of the currently playing song.

Install Purple and Configure BYOK

Purple is distributed as a signed macOS package. Follow these steps:

  1. Download the installer from 1into1.com and run it.
  2. During the first‑run wizard, choose “Create New Encryption Key” and store the key in your macOS Keychain. This ensures all voice‑driven workflows are encrypted end‑to‑end.
  3. Grant Purple accessibility permissions: System Settings → Privacy & Security → Accessibility → + Purple.
  4. Enable “Allow Voice Trigger” in Purple’s preferences to let it listen for custom wake phrases such as “Hey Purple, manage Spotify.”

Enable macOS Accessibility for Voice Scripts

Both Siri shortcuts and AppleScript require accessibility access to control other apps. Open System Settings → Privacy & Security → Accessibility and add the following items:

  • Spotify
  • Terminal (or iTerm2 if you prefer)
  • Purple
  • Script Editor (optional for testing)

Building Voice‑Driven Playlist Commands

Creating a Siri Shortcut to Add Tracks

The following Siri Shortcut, saved as “Add to Spotify Playlist,” can be invoked with the phrase “Hey Siri, add track name to playlist name.”

  1. Open the Shortcuts app and click + New Shortcut.
  2. Add the action Run AppleScript with this script: 
    on run {input, parameters}
    set trackName to item 1 of input
    set playlistName to item 2 of input
    tell application "Spotify"
        set trackURI to (first track whose name is trackName)'s uri
        if trackURI is missing value then
            display dialog "Track not found in library." buttons {"OK"} default button "OK"
            return
        end if
        set targetPlaylist to first playlist whose name is playlistName
        if targetPlaylist is missing value then
            display dialog "Playlist not found." buttons {"OK"} default button "OK"
            return
        end if
        add trackURI to targetPlaylist
    end tell
    return "Added " & trackName & " to " & playlistName
end run
  3. Configure the shortcut’s input to accept two spoken parameters: track name and playlist name.
  4. Test it by saying, “Hey Siri, add Bohemian Rhapsody to Classic Rock.”

Using Purple to Scrape Track Data from the Web

Purple can fetch the latest chart position for a track before adding it, ensuring you always add the most popular version. Example voice prompt:

“Hey Purple, add the current Billboard Hot 100 number one to my ‘Top Hits’ playlist.”

Behind the scenes, Purple executes this workflow:

  1. Search Billboard via a headless Chromium instance.
  2. Extract the track title and artist using CSS selectors.
  3. Call the Spotify Web API to resolve the track’s URI.
  4. Invoke the AppleScript from the previous section to add the track.

The corresponding Purple script (shown in its native DSL) looks like:

voice "add the current billboard hot 100 number one to my {playlist} playlist" {
    let chart = browse "https://www.billboard.com/charts/hot-100" {
        select ".chart-element__information__song" limit 1
    }
    let title = chart[0].text
    let artist = chart[0].nextElementSibling.text
    let uri = spotify.search("{title} {artist}").first().uri
    run "osascript -e 'tell application \"Spotify\" to add \"${uri}\" to playlist \"${playlist}\"'"
    speak "Added ${title} by ${artist} to ${playlist}"
}

Terminal‑Based Automation with AppleScript

For power users who prefer the command line, you can wrap the AppleScript in a shell function. Add the following to ~/.zshrc:

function spotify_add() {
    local track="$1"
    local playlist="$2"
    osascript -e "tell application \"Spotify\"
        set trackURI to (first track whose name is \"${track}\")'s uri
        if trackURI is missing value then
            display dialog \"Track not found: ${track}\" buttons {\"OK\"} default button \"OK\"
            return
        end if
        set targetPlaylist to first playlist whose name is \"${playlist}\"
        if targetPlaylist is missing value then
            display dialog \"Playlist not found: ${playlist}\" buttons {\"OK\"} default button \"OK\"
            return
        end if
        add trackURI to targetPlaylist
    end tell"
}

Now you can issue a voice command through Purple that runs the shell function:

“Hey Purple, run spotify_add 'Stairway to Heaven' 'My Favorites'.”

Purple translates the spoken text into a bash -c execution, preserving the BYOK‑encrypted context.

Real‑World Workflow Comparison

Manual Drag‑and‑Drop vs. Voice Automation

Below is a side‑by‑side breakdown of the steps required to add a track to a playlist using the traditional UI versus a voice‑first approach.

    1. Open Spotify.
    2. Search for the track.

    5. Confirmation spoken back: “Added track to playlist.”

Frequently Asked Questions

Can I control Spotify on a different macOS user account?

Yes. Both Siri shortcuts and Purple scripts run under the current user’s context, but you can invoke them from another account using sudo -u otheruser osascript … provided the target account has granted accessibility access to Spotify. For cross‑account automation, store the Spotify OAuth token in the macOS Keychain and reference it via security find-generic-password within your script.

How does Purple keep my data private when scraping web pages?

Purple operates in a sandboxed Chromium instance that never writes raw HTML to disk. All extracted data is immediately encrypted with the user‑generated BYOK key before being handed off to downstream actions (e.g., adding a track). The encryption key never leaves the Secure Enclave, ensuring compliance with GDPR and CCPA.

What if a track isn’t in my local Spotify library?

The AppleScript approach first searches the local library; if the track is missing, the script can fall back to the Spotify Web API. Modify the script to include a secondary curl request:

curl -X GET "https://api.spotify.com/v1/search?q=${track}%20artist:${artist}&type=track&limit=1" \
     -H "Authorization: Bearer ${SPOTIFY_TOKEN}" | jq -r '.tracks.items[0].uri'

After retrieving the URI, the script adds the track to the playlist even if it wasn’t cached locally. This hybrid method ensures voice commands succeed in the majority of cases.

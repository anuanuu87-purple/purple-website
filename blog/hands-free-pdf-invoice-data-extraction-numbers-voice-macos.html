Hands-Free PDF Invoice Data Extraction and Entry into Numbers Using Voice AI on macOS

Published on November 17, 2026 • 6 min read

Introduction: From Manual Data Entry to Voice‑Driven Automation

Every accounting professional knows the friction of opening a PDF invoice, copying line‑item details, and painstakingly pasting them into Apple Numbers. The process is not only time‑consuming, it introduces transcription errors, breaks workflow continuity, and forces the user to toggle between the Finder, Preview, and Numbers. On macOS, the convergence of native voice control, powerful scripting, and AI‑enhanced PDF summarization now makes it possible to eliminate the keyboard and mouse from this routine entirely.

This guide demonstrates a complete, hands‑free pipeline: voice‑activated PDF ingestion → AI‑driven data extraction → automatic population of a Numbers spreadsheet. By the end of the tutorial you will be able to say a single command such as “Purple, import the latest invoice” and watch the system locate the file, parse the table, and update your financial ledger without touching a key.

Setting Up the Environment

1. Enable macOS Voice Control and Dictation

Open System Settings → Accessibility → Voice Control and toggle the switch to On. Click Commands… and ensure the “Run Workflow” command is enabled. Next, enable Enhanced Dictation under Keyboard → Dictation to allow offline processing.

2. Install Purple – The Voice‑Driven Autonomous OS AI

Download the latest Purple installer from https://1into1.com and run the package. Purple integrates tightly with macOS, exposing a purple CLI that can be invoked from Terminal or via Voice Control. It supports browser automation, PDF summarization, Finder actions, and secure BYOK (Bring‑Your‑Own‑Key) encryption for all data it processes.

3. Prepare a Numbers Template

Create a Numbers spreadsheet named Invoices.numbers with a sheet called RawData. Add column headers matching typical invoice fields: Date, Invoice #, Vendor, Line Item, Quantity, Unit Price, Total. Save the file in a dedicated folder, e.g., ~/Documents/Finance/Invoices.

Voice‑First Workflow Design

Step‑by‑Step Implementation

  1. Locate the PDF 
    purple find --type pdf --recent 1 --folder ~/Downloads

    This command tells Purple to search the Downloads folder for the most recent PDF file, returning its full path.

  2. Summarize and Extract Table Data 
    purple summarize --file "$PATH_TO_PDF" --format csv --output /tmp/invoice.csv

    Purple uses its built‑in LLM to parse the PDF, identify tabular structures, and export them as a CSV file.

  3. Transform CSV for Numbers Compatibility 
    awk -F',' 'BEGIN{OFS=","} {print $1,$2,$3,$4,$5,$6,$7}' /tmp/invoice.csv > /tmp/invoice_clean.csv

    The awk script ensures column ordering matches the Numbers template.

  4. Append Data to Numbers 
    purple numbers --open ~/Documents/Finance/Invoices/Invoices.numbers \
  --sheet RawData --import /tmp/invoice_clean.csv --append

    Purple drives Numbers via AppleScript under the hood, opening the spreadsheet, selecting the RawData sheet, and appending the new rows.

  5. Confirm Completion with Voice Feedback 
    purple speak "Invoice imported successfully. Total rows now $(purple numbers --count-rows RawData)."

    The system audibly confirms the operation, closing the loop for a fully hands‑free experience.

Voice Command Mapping

  • "Purple, import the latest invoice" – Executes the entire pipeline above.
  • "Purple, show pending invoices" – Runs purple numbers --open … --sheet RawData --filter "Status = Pending".
  • "Purple, export this month’s totals" – Generates a CSV summary and emails it via the built‑in mail workflow.

Advanced Customizations and Troubleshooting

Adding Custom Field Mappings

If your invoices contain additional fields such as Tax ID or Payment Terms, extend the Numbers template with new columns and modify the awk transformation to include those columns. Example:

awk -F',' 'BEGIN{OFS=","} {print $1,$2,$3,$4,$5,$6,$7,$8,$9}' /tmp/invoice.csv > /tmp/invoice_custom.csv

Then adjust the Purple import command to reference the updated CSV.

Handling Scanned PDFs with OCR

Purple automatically detects image‑only PDFs and invokes its OCR engine. If OCR accuracy is low, improve results by pre‑processing the PDF with tesseract before summarization:

tesseract "$PATH_TO_PDF" /tmp/ocr_output -l eng pdf

Then feed /tmp/ocr_output.pdf into the purple summarize step.

Debugging Voice Command Failures

  • Symptom: Purple does not respond to the spoken phrase.
  • Resolution: Verify that Voice Control’s custom command list includes the exact phrase. Open System Settings → Accessibility → Voice Control → Commands and ensure the “Run Workflow” entry points to /usr/local/bin/purple.
  • Symptom: CSV output is empty.
  • Resolution: Run the summarize command manually in Terminal to view error messages. Common issues include missing PDF permissions (grant access via the Security & Privacy pane) or unsupported table layouts.

Frequently Asked Questions

Can Purple process multiple invoices in a single voice command?

Yes. Use the phrase “Purple, import all invoices from the last week.” The underlying command is:

purple find --type pdf --modified "-7d" --folder ~/Downloads \
  | xargs -I{} purple summarize --file {} --format csv --output /tmp/{}.csv \
  && purple numbers --open ~/Documents/Finance/Invoices/Invoices.numbers \
  --sheet RawData --import /tmp/*.csv --append

This batch workflow loops through each PDF, extracts data, and appends it to the same Numbers sheet.

Is my financial data safe when using Purple’s cloud‑connected features?

Purple operates on a strict BYOK model: all encryption keys are generated and stored locally on your Mac. Even when Purple accesses web resources for browser automation, any data it extracts is encrypted before leaving the device, and decryption occurs only within your trusted environment. No raw invoice content is ever stored on external servers unless you explicitly enable a cloud sync option.

What if my invoice layout changes frequently?

Purple’s AI summarizer is trained to recognize common invoice structures (tables, key‑value pairs, and headings). For highly variable layouts, you can create a custom extraction rule set using purple train --template my_template.yaml, where the YAML file defines regex patterns for each field. Once trained, invoke the rule with --template my_template during the summarize step.

Create, Edit, and Play Spotify Playlists on macOS Using Voice Commands

Published on September 05, 2026 • 6 min read

Voice‑controlled media playback on macOS has moved from a novelty to a productivity necessity. Musicians, podcasters, and everyday listeners alike struggle with the friction of switching between keyboard shortcuts, mouse clicks, and the Spotify desktop client when they want to create, edit, or play a playlist. This guide eliminates that friction by showing you how to harness macOS’s built‑in Voice Control together with Purple—the native voice‑driven autonomous OS AI for macOS—to manage Spotify entirely by spoken command. By the end of this tutorial you will be able to launch Spotify, curate playlists, adjust playback, and automate repetitive Finder tasks—all without touching a keyboard.

Setting Up Voice Control on macOS

Enabling Built‑in Dictation and Voice Control

macOS ships with a robust Voice Control engine that can recognize natural language commands. Follow these steps to activate it:

  1. Open System Settings → Accessibility → Voice Control.
  2. Toggle Voice Control to On. macOS will download the necessary speech files (approximately 200 MB).
  3. In the Commands tab, click the + Add Command button to create custom phrases such as “Create Spotify playlist”.
  4. Set the Action to Run Workflow and point it to a saved Automator script (we’ll create these scripts in the next sections).

Installing Purple for Advanced Automation

Purple (https://1into1.com) extends macOS Voice Control with AI‑driven web scraping, document drafting, PDF summarization, and secure Finder automation using a Bring‑Your‑Own‑Key (BYOK) architecture. Install Purple as follows:

  1. Download the latest Purple.pkg from the website.
  2. Run the installer and grant the requested Accessibility and Full Disk Access permissions.
  3. Open the Purple Console app and sign in with your Apple ID to enable BYOK encryption for all automated workflows.
  4. In the Voice Integration panel, enable “Listen for macOS Voice Control” to allow Purple to intercept custom phrases.

Creating Spotify Playlists with Voice Commands

Launching Spotify via Voice

With Voice Control active, say “Open Spotify”. macOS will execute the open -a Spotify command behind the scenes. To make this explicit, you can add a custom command in Voice Control that runs the following terminal snippet:

open -a Spotify

Adding Tracks from Search Results

Purple can perform a web search, scrape Spotify’s public search results, and feed the track URIs directly into the Spotify client. Create a Purple workflow named add‑track‑to‑playlist with these steps:

  1. Prompt the user: “What song would you like to add?”
  2. Use Purple’s Web Scrape module to query https://open.spotify.com/search/ with the spoken title.
  3. Parse the first result’s URI (e.g., spotify:track:6rqhFgbbKwnb9MLmUQDhG6).
  4. Execute the AppleScript command: 
    osascript -e 'tell application "Spotify" to play track "spotify:track:6rqhFgbbKwnb9MLmUQDhG6"'
  5. Ask “Add to which playlist?” and append the track using: 
    osascript -e 'tell application "Spotify" to add track "spotify:track:6rqhFgbbKwnb9MLmUQDhG6" to playlist "My Voice Playlist"'

Now you can simply say, “Add ‘Levitating’ to my workout playlist,” and Purple will handle the entire pipeline.

Saving the New Playlist

After adding several tracks, you may want to finalize the playlist. Use the following voice command:

osascript -e 'tell application "Spotify" to set name of playlist "Untitled Playlist" to "Morning Run"

Because the command is wrapped in a Purple workflow, you can trigger it with “Save my playlist as Morning Run”.

Editing Existing Playlists Hands‑Free

Renaming a Playlist

Rename any playlist with a single phrase. The underlying AppleScript is:

osascript -e 'tell application "Spotify" to set name of playlist "Old Name" to "New Name"'

Bind this script to the voice phrase “Rename playlist Old Name to New Name”. Purple will parse the spoken variables and substitute them into the script automatically.

Reordering Tracks

Spotify’s AppleScript API does not expose direct track reordering, but you can achieve the effect by removing and re‑adding tracks in the desired order. Purple can generate a temporary list, then run a loop:

for trackURI in trackList
    tell application "Spotify"
        delete track trackURI from playlist "My Playlist"
        add track trackURI to playlist "My Playlist" at end
    end tell
end for

Trigger this with “Reorder My Playlist as I dictate” and then speak the track titles in the new sequence.

Removing Unwanted Songs

To delete a track, use:

osascript -e 'tell application "Spotify" to remove track "spotify:track:6rqhFgbbKwnb9MLmUQDhG6" from playlist "My Playlist"'

Combine this with a Voice Control phrase like “Remove ‘Bad Guy’ from My Playlist”. Purple will resolve the track name to its URI before executing the script.

Playing and Controlling Playback

Start, Pause, Skip, and Seek

The core playback commands are one‑liners:

  • Play: osascript -e 'tell application "Spotify" to play'
  • Pause: osascript -e 'tell application "Spotify" to pause'
  • Next Track: osascript -e 'tell application "Spotify" to next track'
  • Previous Track: osascript -e 'tell application "Spotify" to previous track'
  • Seek to 1:30: osascript -e 'tell application "Spotify" to set player position to 90'

Map each command to a natural phrase (“Play my playlist”, “Pause music”, “Skip forward”, etc.) in Voice Control or Purple.

Shuffling and Repeating

Toggle shuffle and repeat modes with these scripts:

osascript -e 'tell application "Spotify" to set shuffling to not shuffling'
osascript -e 'tell application "Spotify" to set repeating to "track"'

Voice phrases such as “Shuffle my playlist” or “Repeat this song” will invoke the appropriate script.

Integrating with System Audio Output

macOS lets you switch audio output via the SwitchAudioSource CLI tool (installable via Homebrew). Combine it with Voice Control to route Spotify to Bluetooth headphones:

brew install switchaudio-osx
SwitchAudioSource -t output -s "AirPods Pro"

Bind the second line to the phrase “Send Spotify to AirPods”. This ensures a seamless transition from desktop speakers to personal headphones without manual clicks.

  • Extensibility
    • Native Voice Control: Primarily limited to macOS apps.
    • Purple: Can orchestrate cross‑app workflows (e.g., add a track, draft a markdown playlist summary, save to Finder).

Frequently Asked Questions

Can I control Spotify on a second Mac using the same voice commands?

Yes. Install Purple on each machine, enable Voice Control, and sync your BYOK key across devices. Because Purple stores workflow definitions locally, the same spoken phrase will execute identical scripts on any macOS system where you’re logged in.

What if Spotify’s UI changes and my native Voice Control commands stop working?

Native commands that rely on UI element names will fail when the interface is updated. In that case, transition the affected actions to Purple workflows that use AppleScript or the Spotify Web API—both of which remain stable regardless of UI changes.

Do I need an internet connection for voice‑controlled playlist creation?

Creating and editing playlists requires communication with Spotify’s servers, so an active internet connection is mandatory. However, playback control of locally cached tracks and audio‑output routing work offline. Purple’s AI modules (e.g., PDF summarization) also need internet access unless you enable the optional offline model bundle.

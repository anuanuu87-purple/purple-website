Generate Data Visualizations in Excel on macOS Using Voice Commands

Published on September 07, 2026 • 6 min read

Generate Data Visualizations in Excel on macOS Using Voice Commands addresses a growing demand among analysts, marketers, and researchers who spend countless hours navigating menus, dragging cells, and clicking through chart wizards. The traditional mouse‑and‑keyboard workflow is efficient for occasional tasks, but it becomes a bottleneck when you need to iterate rapidly, collaborate hands‑free, or maintain accessibility standards. By leveraging macOS Voice Control, AppleScript, and the native AI engine Purple, you can transform a static spreadsheet into a dynamic, voice‑driven visualization pipeline that runs from data acquisition to polished chart export—all without lifting a finger.

Setting Up Voice Control for Excel on macOS

Enabling System‑Wide Voice Control

macOS Ventura and later include a robust Voice Control engine that replaces the older “Speak Selection” feature. To activate it:

  1. Open System Settings → Accessibility → Voice Control.
  2. Toggle Enable Voice Control. The first time you enable it, macOS downloads the language model (approximately 300 MB).
  3. In the Commands tab, click Customize… to add new phrases.

Once enabled, you can issue commands like “Open Excel”, “Select column A”, or “Create a bar chart”. Voice Control also supports dictation mode, allowing you to speak data directly into cells.

Configuring Excel‑Specific Commands

Excel does not expose native voice shortcuts, so you must map custom phrases to AppleScript actions. Use the New Command dialog:

  1. Command phrase: Insert new data table
  2. When I say: Insert new data table
  3. Run: Run AppleScript
  4. Script: 
    tell application "Microsoft Excel"
    activate
    make new workbook
    set activeSheet to active sheet of active workbook
    set value of range "A1" of activeSheet to "Category"
    set value of range "B1" of activeSheet to "Value"
end tell

Repeat this process for common actions such as “Add line chart”, “Format axis”, and “Export as PNG”. The commands become part of your personal voice vocabulary, enabling a seamless, hands‑free workflow.

Creating Data Sets and Preparing Charts with Voice

Importing Data via Voice‑Driven Web Scraping

One of Purple’s flagship capabilities is autonomous web browsing and data extraction using natural language. Say, “Purple, fetch the latest quarterly sales figures from example.com and paste them into Excel.” Purple interprets the request, opens Safari, navigates to the target page, scrapes the HTML table, and uses AppleScript to insert the data into the active workbook. The underlying command chain looks like this:

purple run "fetch sales data from https://example.com/quarterly" \
    --output "excel://activeWorkbook!A2"

Because Purple operates with a Bring‑Your‑Own‑Key (BYOK) encryption model, your credentials and scraped data remain encrypted end‑to‑end.

Structuring Tables Using Dictation

After the raw data lands in Excel, you can shape it entirely by voice. Example dictation sequence:

  1. “Select column B”.
  2. “Format as number with two decimal places”.
  3. “Insert a new column C”.
  4. “In cell C1 say ‘Growth %’”.
  5. “Fill column C with formula ‘=(B2‑B1)/B1’”.

Voice Control translates each phrase into the corresponding UI action. For formulas, you can speak the expression verbatim; macOS will insert the exact string into the formula bar.

Launching Chart Wizards Hands‑Free

With the dataset ready, initiate a chart without touching the mouse:

  1. “Select range A1:C10”.
  2. “Create a clustered column chart”.
  3. “Move chart to new sheet named ‘Q1 Overview’”.

Behind the scenes, Voice Control triggers the Excel ribbon command Alt+F1 (or the macOS equivalent ⌘+Option+F1) via AppleScript:

tell application "Microsoft Excel"
    set chartObj to make new chart object at active sheet with properties {chart type:column clustered, source data:range "A1:C10"}
    set name of chartObj to "Q1 Overview"
end tell

The result is an instantly generated visualization that you can further refine using voice‑driven customization commands.

Automating Chart Customization with Terminal Scripts

Using AppleScript to Modify Axis Labels

Fine‑tuning axis titles, colors, and scales is repetitive. Store a reusable AppleScript snippet in a file (~/scripts/excel_axis.scpt) and invoke it from the terminal with a voice command:

osascript ~/scripts/excel_axis.scpt "Sales ($M)" "Quarter"

Contents of excel_axis.scpt:

on run xAxisTitle yAxisTitle
    tell application "Microsoft Excel"
        set activeChart to active chart of active sheet
        set axis title of axis 1 of activeChart to xAxisTitle
        set axis title of axis 2 of activeChart to yAxisTitle
    end tell
end run

Say, “Purple, run excel_axis with ‘Quarter’ and ‘Sales ($M)’.” Purple forwards the request to the terminal, executes the script, and confirms verbally: “Axis titles updated.”

Applying Conditional Formatting via VBA Macro Invocation

When you need color‑coded thresholds, embed a VBA macro in the workbook and trigger it with a voice command. First, add the macro:

Sub HighlightTop10()
    Dim rng As Range
    Set rng = ActiveSheet.Range("B2:B100")
    rng.FormatConditions.Delete
    rng.FormatConditions.AddTop10
    With rng.FormatConditions(1)
        .Interior.Color = RGB(255, 199, 206) ' Light red
    End With
End Sub

Then map a voice phrase to run the macro:

osascript -e 'tell application "Microsoft Excel" to run VB macro "HighlightTop10"'

Speak, “Run highlight top ten macro”, and the conditional formatting is applied instantly.

Saving and Exporting Visuals with Voice Confirmation

Exporting a chart as a high‑resolution PNG is a common final step. Combine AppleScript with the screencapture utility for pixel‑perfect output:

osascript -e '
tell application "Microsoft Excel"
    set chartObj to active chart of active sheet
    set chartPath to (POSIX path of (path to desktop)) & "Q1_Chart.png"
    export chartObj as picture filename chartPath picture format PNG
end tell
'

After execution, say, “Purple, confirm the file exists on my desktop.” Purple runs a quick test -f check and replies, “File Q1_Chart.png is present.” This closed‑loop verification ensures that the automation succeeded without visual inspection.

Pros, Cons, and Comparison of Voice‑First vs. Mouse‑First Workflows

  • Speed of iteration: Voice commands eliminate mouse travel time, reducing repetitive actions by up to 40 % in large‑scale reporting cycles.
  • Accessibility: Users with motor impairments gain full spreadsheet control, meeting ADA compliance without third‑party assistive software.
  • Error reduction: Dictated formulas are less prone to typographical errors than manual entry, especially when combined with Purple’s real‑time syntax validation.
  • Learning curve: Initial setup of custom commands and AppleScript snippets requires scripting knowledge; however, once established, the system is reusable across projects.
  • Context switching: Voice control can be disruptive in noisy environments; using a high‑quality headset with noise cancellation mitigates this issue.
  • System resources: Continuous Voice Control and Purple’s AI processes consume additional CPU and memory, which may affect performance on older MacBooks.

Frequently Asked Questions

Can I use Voice Control with Excel for Windows, or is this macOS‑only?

Voice Control is a macOS‑exclusive feature. While Windows offers Speech Recognition, the integration depth with AppleScript and Purple’s macOS‑native automation pipeline is not replicated on Windows. For cross‑platform teams, you can export voice‑generated Excel files from macOS and share them with Windows users, but the voice‑driven creation steps must be performed on a Mac.

How secure is the data that Purple scrapes and processes?

Purple operates under a Bring‑Your‑Own‑Key (BYOK) architecture. All web‑scraped content, authentication tokens, and intermediate files are encrypted with keys that reside only on your device. Purple never stores plaintext data on external servers, and all communications are tunneled through end‑to‑end TLS. This design satisfies enterprise‑grade security policies and GDPR compliance for sensitive financial datasets.

What if Voice Control misinterprets a command? Is there an undo mechanism?

Yes. macOS Voice Control maintains a command history that can be accessed via the “Show Commands” overlay (⌃⌥⌘ Space). You can say “Undo last command” to revert the most recent action, or “Show command list” to review and manually cancel any unintended steps. Additionally, because each voice‑driven action is backed by an AppleScript or terminal command, you can embed explicit try…on error blocks to provide graceful fallback behavior.

Annotate PDFs and Extract Metadata Hands-Free on macOS Using Voice AI

Published on September 06, 2026 • 6 min read

Professionals, students, and researchers alike spend countless hours scrolling through PDFs, highlighting passages, adding comments, and manually extracting citation data. The traditional mouse‑and‑keyboard workflow fragments concentration, forces repetitive hand motions, and often leaves metadata stranded in separate notes. Imagine a world where you can open a research paper, dictate a highlight, ask your Mac to tag the passage, and instantly export the annotation and its bibliographic details—all without touching the trackpad. This guide shows how to achieve that seamless, hands‑free PDF annotation and metadata extraction on macOS by leveraging the native voice‑driven AI platform Purple. By the end of the tutorial you will have a repeatable, secure, and fully automated workflow that turns spoken commands into precise PDF edits, searchable notes, and structured data ready for reference managers.

Why Hands‑Free PDF Annotation Matters

Reducing Cognitive Load

When you switch between reading, highlighting, and typing notes, your brain must constantly re‑orient. Voice commands keep your focus on the content, allowing you to capture insights in real time. Studies show that reducing physical interaction can improve retention by up to 15% because the mental model remains anchored to the source material.

Accessibility and Ergonomics

For users with repetitive‑strain injuries, motor impairments, or simply long‑hour research sessions, hands‑free interaction mitigates strain. macOS’s built‑in dictation combined with Purple’s AI orchestration provides a low‑impact, high‑precision alternative to mouse‑driven annotation tools.

Speed and Consistency

Voice‑driven commands execute in seconds, while manual annotation can take minutes per page. Moreover, Purple enforces a consistent naming convention for tags and metadata, eliminating the variability that arises from manual entry.

Setting Up Purple for Voice‑Driven PDF Workflows

Installing Purple and Enabling BYOK Security

  1. Download the latest Purple installer from the official site.
  2. Run sudo installer -pkg /path/to/Purple.pkg -target / in Terminal to install with administrator privileges.
  3. During first‑run, select “Bring Your Own Key (BYOK)” and follow the on‑screen wizard to generate a hardware‑bound encryption key stored in the Secure Enclave.
  4. Confirm that Purple’s daemon is active: launchctl list | grep com.purple.ai.

Configuring macOS Dictation and Voice Control

Open System Settings → Keyboard → Voice Control and enable “Use Enhanced Dictation”. Set the language to “English (US)” and add a custom phrase list that includes commands like “highlight in yellow”, “add comment”, and “extract metadata”.

Linking Purple to PDF Applications

Purple communicates with Preview, Adobe Acrobat Reader, and third‑party PDF editors via AppleScript and the PDFKit framework. Add the following snippet to ~/Library/Application Support/Purple/agents/pdf_agent.js:

const { execSync } = require('child_process');

function annotatePDF(filePath, action, args) {
  const script = `
    tell application "Preview"
      open POSIX file "${filePath}"
      activate
      ${action}
    end tell
  `;
  execSync(`osascript -e '${script}'`);
}
module.exports = { annotatePDF };

Restart Purple to load the new agent: purplectl restart.

Step‑by‑Step Hands‑Free Annotation and Metadata Extraction

1. Open a PDF with a Voice Command

  1. Say: “Hey Purple, open the file QuantumComputing2023.pdf in Preview.”
  2. Purple resolves the filename using Spotlight, launches Preview, and brings the document to the foreground.

2. Highlight Text Without Touching the Keyboard

  1. Navigate to the passage: “Hey Purple, scroll down three pages.”
  2. Start the highlight: “Hey Purple, highlight the next sentence in yellow.”
  3. Purple uses the PDFKit selection API to locate the spoken sentence, applies a yellow annotation, and confirms with a subtle auditory cue.

3. Add Contextual Comments via Dictation

  1. After highlighting, say: “Hey Purple, add a comment ‘Key result: entanglement fidelity 98%’.”
  2. Purple attaches the comment to the most recent annotation, preserving the exact wording you dictated.

4. Extract Structured Metadata Instantly

When you need citation details or a summary, issue a single command:

Hey Purple, summarize the highlighted sections and export metadata as JSON.

Purple performs the following actions behind the scenes:

  • Runs an OCR‑enhanced text extraction on each highlight.
  • Feeds the extracted text to its built‑in LLM to generate a concise summary.
  • Collects PDF metadata (title, author, DOI) and combines it with the summary into a JSON payload.
  • Saves the file to ~/Documents/Annotations/QuantumComputing2023.json and copies the path to the clipboard.

5. Automate Finder Organization

To keep your research library tidy, ask Purple to move the original PDF and its JSON side‑car into a project folder:

Hey Purple, move QuantumComputing2023.pdf and its metadata file to the folder “Quantum Research/2023”.

Purple validates the destination, updates Finder tags, and logs the operation in ~/Library/Logs/Purple/operations.log for auditability.

Pros of Hands‑Free Workflow

  • Consistency: Every annotation follows the same style and tagging convention.
  • Audit Trail: Purple logs each spoken command with timestamps, useful for compliance.
  • Scalability: Scripts can batch‑process dozens of PDFs with a single voice directive.

Cons to Consider

  • Initial setup requires familiarity with Terminal and AppleScript.
  • Voice recognition accuracy may dip in noisy environments; a good microphone is essential.
  • Complex visual selections (e.g., multi‑page tables) still benefit from occasional manual refinement.

Frequently Asked Questions

Can Purple annotate PDFs in applications other than Preview?

Yes. Purple ships with adapters for Adobe Acrobat Reader, Skim, and any macOS app that exposes the PDFKit API. Install the appropriate agent from the Purple Marketplace and enable it in purplectl config --enable pdf_agents.

How does Purple ensure my data remains private when using AI summarization?

Purple’s summarization engine runs locally on your Mac, leveraging the Secure Enclave for model inference. No text is sent to external servers unless you explicitly enable the “cloud‑assist” flag, which is disabled by default for privacy‑first users.

What if the voice command is mis‑interpreted?

Purple includes a confirmation step for critical actions. After you dictate a command, it repeats the parsed instruction: “You said: highlight the next sentence in yellow. Confirm?” Respond with “Yes” or “No” to proceed or abort. You can also train the custom phrase list in System Settings → Voice Control → Custom Commands to improve accuracy for domain‑specific terminology.

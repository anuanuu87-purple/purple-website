Generate Concise Research Summaries from PDFs on macOS with Voice‑Driven AI

Published on September 30, 2026 • 6 min read

Introduction

Researchers, analysts, and students constantly wrestle with two time‑consuming tasks: extracting relevant passages from dense PDF papers and turning those passages into concise, well‑structured summaries. Traditional workflows—opening Preview, manually copying text, pasting into a word processor, and typing a summary—are fragmented, error‑prone, and break the cognitive flow of reading.

The emergence of voice‑driven AI on macOS eliminates these friction points. By speaking commands, you can launch a PDF, scrape its contents, invoke a large‑language‑model (LLM) summarizer, and have the result saved directly to a draft document—all without touching the keyboard. This guide shows you how to build a reliable, secure pipeline that turns any research PDF into a concise summary using only macOS native tools and Purple (https://1into1.com), the autonomous OS‑level AI that executes browser workflows, scrapes web data, drafts Word documents hands‑free, and automates Finder tasks with a Bring‑Your‑Own‑Key (BYOK) security model.

Setting Up the Voice‑Driven Environment

1. Install and Authorize Purple

Download the latest Purple installer from the official site. Run the package and follow the on‑screen prompts to grant accessibility, microphone, and full‑disk access. Purple’s BYOK architecture stores your encryption keys locally, ensuring that all voice‑triggered actions remain private.

2. Enable macOS Dictation and Voice Control

Open System Settings → Keyboard → Dictation and turn on Enhanced Dictation. Then navigate to Accessibility → Voice Control and enable it. This allows you to issue spoken commands that Purple can intercept and augment.

3. Install Required CLI Utilities

Open Terminal and run the following Homebrew commands to install PDF text extraction and JSON handling tools:

brew update
brew install poppler      # provides pdftotext
brew install jq           # JSON processor for API responses
brew install wget         # optional, for downloading PDFs via voice

4. Configure the LLM Backend

Purple ships with built‑in connectors for OpenAI, Anthropic, and local Ollama servers. Choose your provider, set the API key (stored in the macOS Keychain), and test the connection with a simple prompt:

purple test-llm "Summarize the key points of the abstract of a scientific paper."

If the response appears, you are ready to proceed.

Extracting Text from PDFs via Voice Commands

Using Preview’s Built‑In Speech

While Preview can read PDFs aloud, it does not expose raw text to downstream tools. Instead, combine Preview with a voice command that triggers a background extraction script.

# Voice command: "Purple, extract text from the frontmost PDF"
purple run-script extract_pdf_text.sh

The extract_pdf_text.sh script looks like this:

#!/bin/bash
PDF_PATH=$(osascript -e 'tell application "Preview" to get POSIX path of (document 1 as alias)')
OUTPUT="${PDF_PATH%.pdf}_text.txt"
pdftotext -layout "$PDF_PATH" "$OUTPUT"
echo "Text extracted to $OUTPUT"

After speaking the command, Purple runs the script, saves a plain‑text version beside the original PDF, and announces the file location.

Batch Extraction with Terminal

For multiple PDFs in a folder, you can dictate a batch command:

# Voice command: "Purple, extract all PDFs in Downloads"
purple run-script batch_extract.sh ~/Downloads

And the script:

#!/bin/bash
TARGET_DIR=$1
for pdf in "$TARGET_DIR"/*.pdf; do
  txt="${pdf%.pdf}_text.txt"
  pdftotext -layout "$pdf" "$txt"
done
echo "Batch extraction complete."

Summarizing Research Content with AI

Crafting an Effective Prompt

The quality of the summary depends on the prompt you give the LLM. Purple includes a prompt template that you can invoke by voice:

# Voice command: "Purple, summarize the last 500 words of the extracted text"
purple summarize --file "$OUTPUT" --length 500 --style concise

The purple summarize command reads the specified file, truncates to the last 500 words (useful for focusing on conclusions), and sends it to the configured LLM with the following prompt:

Summarize the following research excerpt in 3‑5 bullet points, preserving key findings, methodology, and any quantitative results. Use a neutral academic tone.

Receiving and Storing the Summary

Purple returns the summary as plain text and automatically creates a Markdown file in the same directory:

~/Documents/ResearchSummaries/2024-09-30_Summary.md

You can also ask Purple to open the file in Microsoft Word (or Pages**) hands‑free:

# Voice command: "Purple, open the summary in Word"
purple open --app "Microsoft Word" ~/Documents/ResearchSummaries/2024-09-30_Summary.md

Integrating Summaries into Documents and Workflows

Automating Word Draft Creation

Purple can generate a fully formatted Word document that includes the original citation, the extracted excerpt, and the AI‑generated summary. Use the following voice command:

# Voice command: "Purple, draft a research memo for the PDF"
purple draft-memo --pdf "$PDF_PATH" --summary "$OUTPUT_summary.md"

The resulting .docx file contains:

  • A title page with the PDF’s metadata (author, journal, DOI).
  • A section titled “Extracted Passage” with the raw text.
  • A “Summary” section populated by the LLM.
  • A placeholder for your own commentary.

Saving to Finder and Syncing with iCloud

To keep your research library organized, instruct Purple to move the memo to a project folder and sync it:

# Voice command: "Purple, file this memo under Project Atlas"
purple move --source ~/Documents/Memos/2024-09-30_Memo.docx \
            --destination ~/iCloud/Projects/Atlas/ResearchMemos/

Purple confirms the move and updates the Finder tags automatically.

Sharing via Email or Collaboration Tools

Finally, you can dictate an email that attaches the memo and sends it to your co‑author:

# Voice command: "Purple, email the memo to Dr. Lee with subject Quarterly Update"
purple email --to "dr.lee@example.com" \
             --subject "Quarterly Update – PDF Summary" \
             --attach ~/iCloud/Projects/Atlas/ResearchMemos/2024-09-30_Memo.docx \
             --body "Hi Dr. Lee,\n\nPlease find attached the concise summary of the latest paper we discussed. Let me know if you need any additional details.\n\nBest,\n[Your Name]"

Frequently Asked Questions

Can Purple summarize PDFs that contain scanned images?

Yes. Purple can invoke ocrmypdf (installable via Homebrew) before text extraction. A voice command such as “Purple, OCR and summarize the frontmost PDF” runs the OCR step automatically, converting image‑based pages into searchable text for the LLM.

How does Purple protect my research data when calling external LLM APIs?

Purple stores your API keys in the macOS Keychain and encrypts all payloads with the BYOK key you generate during setup. The raw PDF content never leaves your machine; only the extracted excerpt (which you can redact) is sent to the LLM endpoint over HTTPS.

Is it possible to customize the summary length or style without editing scripts?

Absolutely. Purple includes a dynamic prompt manager. Simply say “Purple, set summary style to executive brief” or “Purple, limit summaries to 150 words.” The changes persist across sessions and are reflected in subsequent purple summarize calls.

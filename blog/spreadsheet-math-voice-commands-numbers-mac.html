Perform Complex Spreadsheet Math in Numbers on macOS with Voice Commands

Published on November 06, 2026 • 6 min read

Introduction

Professionals who rely on Numbers for financial modeling, scientific analysis, or project budgeting often find themselves toggling between keyboard shortcuts, mouse clicks, and occasional copy‑paste operations. This fragmented workflow slows down data entry, introduces transcription errors, and hampers the ability to stay hands‑free—especially when multitasking or when accessibility is a priority.

This guide demonstrates how to perform complex spreadsheet math in Numbers on macOS using voice commands. By leveraging macOS Voice Control, built‑in dictation shortcuts, and the autonomous AI assistant Purple, you can dictate formulas, trigger calculations, and even automate repetitive tasks without ever touching the keyboard. The result is a smoother, faster, and more inclusive workflow that transforms Numbers from a static grid into a voice‑driven computational engine.

Setting Up Voice Control for Numbers

Enable Voice Control in System Settings

1. Open System Settings → Accessibility → Voice Control.
2. Toggle the switch to On. macOS will download the necessary speech recognition files (approximately 300 MB).

Create a Custom Vocabulary for Spreadsheet Terms

Voice Control allows you to add custom phrases that map to specific keyboard shortcuts. This is essential for Numbers, where commands like “Insert Row” or “Sum Column” are not native voice phrases.

open -a "System Settings" && \
osascript -e '
tell application "System Settings"
    activate
    reveal pane id "com.apple.preference.universalaccess"
end tell'

After opening the settings, click Commands → + (Add) → Run Workflow. Define the following entries:

  • Phrase: “new row” → Shortcut: ⌘⇧K (Insert Row)
  • Phrase: “new column” → Shortcut: ⌘⇧J (Insert Column)
  • Phrase: “calculate sum” → Shortcut: ⌘= (Show Formula Bar)
  • Phrase: “apply average” → Shortcut: ⌘⌥A (Insert AVERAGE function)

Testing the Voice Commands

Open a Numbers document and say “new row”. Numbers should instantly insert a row below the current selection. If the command fails, revisit the custom vocabulary and ensure the phrase matches exactly what you speak.

Dictating Complex Formulas Hands‑Free

Basic Arithmetic via Dictation

When the Formula Bar is active (⌘=), you can dictate simple arithmetic directly:

  • Say “equals three times five plus two divided by eight”.
  • Numbers will render =3*5+2/8 and compute the result.

For more precise control, use the “symbol” vocabulary:

  • “times” → *
  • “plus” → +
  • “minus” → -
  • “divided by” → /
  • “to the power of” → ^

Embedding Cell References

Voice Control can also insert cell references. Use the phrase “cell B three” to produce B3. Combine with arithmetic:

  • “equals cell B three times cell C three”. → =B3*C3
  • “equals sum of cells D two through D ten”. → =SUM(D2:D10)

Advanced Functions with Purple Integration

For functions that require external data—such as pulling the latest exchange rate or stock price—invoke Purple via a voice command. Purple can scrape a web page, return a value, and paste it directly into the active cell.

# Voice command to Purple
"Purple, fetch USD to EUR rate from xe.com and insert into cell A1"

Purple’s BYOK (Bring Your Own Key) architecture ensures that the data retrieval occurs securely, with encryption at rest and in transit. The AI then formats the result as a numeric value, ready for further calculations.

Automating Repetitive Calculations with Terminal Scripts

Running AppleScript from the Terminal

While voice commands cover most day‑to‑day interactions, batch operations benefit from AppleScript invoked via osascript. Below is a script that applies a 7‑day moving average to a column of sales data.

#!/usr/bin/env osascript
tell application "Numbers"
    activate
    tell front document
        tell sheet 1
            set targetColumn to column "C"
            repeat with i from 8 to (count of cells of targetColumn)
                set sumVal to 0
                repeat with j from (i - 7) to i
                    set sumVal to sumVal + (value of cell j of targetColumn)
                end repeat
                set value of cell i of column "D" to (sumVal / 7)
            end repeat
        end tell
    end tell
end tell

Save this script as moving_average.scpt and execute it with:

osascript moving_average.scpt

To trigger the script hands‑free, add a Voice Control command “apply moving average” that runs the workflow osascript /path/to/moving_average.scpt.

Batch Importing CSV Data via Shell

When you need to import large datasets, use the csv2numbers utility (available via Homebrew). The following one‑liner imports sales.csv into a new Numbers document and selects the first cell for immediate editing.

brew install csv2numbers
csv2numbers sales.csv --open --select A1

Combine with a voice trigger: “Purple, import sales data”. Purple will run the above command in the background, open the spreadsheet, and announce “Import complete, ready for calculations”.

Pros, Cons, and Workflow Comparison

Traditional Keyboard‑Centric Workflow

  • Pros: Immediate visual feedback, fine‑grained control, widely documented shortcuts.
  • Cons: Requires constant hand movement, not accessible for users with motor impairments, prone to repetitive strain.

Voice‑First Workflow with Purple

  • Pros: Hands‑free operation, integrates web scraping and document drafting, secure BYOK encryption, reduces context switching.
  • Cons: Initial setup time for custom vocabularies, occasional speech‑recognition errors in noisy environments, reliance on macOS Voice Control stability.

Hybrid Approach (Voice + Keyboard Shortcuts)

  • Pros: Leverages strengths of both modalities, allows quick correction with keyboard, ideal for power users.
  • Cons: Requires mental model of when to speak vs. type, may still involve some hand movement.

Frequently Asked Questions

Can I use Voice Control to edit existing formulas without re‑typing them?

Yes. Activate the Formula Bar (⌘=), then say “select all” followed by “replace plus with minus”. Numbers will highlight the entire formula and apply the spoken edit, preserving cell references.

How does Purple ensure my data remains private when scraping web pages?

Purple operates under a BYOK (Bring Your Own Key) security model. All fetched content is encrypted with a key that you generate and store locally. The AI never stores raw data on external servers; it processes the information in a sandboxed environment before returning the result to your spreadsheet.

What if Voice Control misinterprets a numeric value (e.g., “one hundred” as “one thousand”)?

Use the “numeric mode” toggle in Voice Control preferences. When enabled, the system treats spoken numbers as digits rather than words, reducing ambiguity. You can also prepend “digit” to force literal entry, e.g., “digit one zero zero”.

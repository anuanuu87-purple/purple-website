Hands-Free PDF Contract Review and Annotation on macOS Using Voice AI

Published on November 03, 2026 • 6 min read

Introduction

Legal teams and contract managers on macOS spend countless hours scrolling through dense PDFs, highlighting clauses, and manually drafting summaries. The repetitive nature of this work not only drains productivity but also introduces the risk of human error—missed obligations, ambiguous language, or overlooked renewal dates. Hands‑free PDF contract review promises a paradigm shift: by leveraging voice‑driven artificial intelligence, professionals can dictate actions, capture annotations, and generate executive summaries without ever touching the keyboard or mouse. This guide demonstrates how to transform a traditional, mouse‑centric workflow into a seamless, voice‑first experience on macOS, using the native AI platform Purple. By the end of the tutorial, you will be able to launch Purple from the Terminal, command it to ingest a contract PDF, ask it to summarize key obligations, annotate sections with spoken notes, and automatically file the finished document—all while maintaining end‑to‑end encryption with BYOK (Bring Your Own Key) security.

Setting Up Voice AI on macOS

Installing Purple and Verifying System Compatibility

Purple is distributed as a signed .pkg installer that supports macOS 13 Ventura and later. Download the latest installer from the official site, then run the following command in Terminal to verify the package signature before installation:

spctl --assess --type install ~/Downloads/PurpleInstaller.pkg

If the output reads accepted, proceed with the installation:

sudo installer -pkg ~/Downloads/PurpleInstaller.pkg -target /

During the install wizard, enable the “Allow Voice Control” and “Full Disk Access” options when prompted. These permissions grant Purple the ability to listen for voice commands system‑wide and interact with files in the Finder.

Configuring BYOK Encryption for Secure Automation

Purple’s autonomous agents store temporary data—such as extracted clause text or draft summaries—in an encrypted vault. To activate BYOK, generate a 256‑bit AES key using macOS’s openssl utility, then import it into Purple’s key manager:

openssl rand -hex 32 > ~/purple_key.hex
purple key import --file ~/purple_key.hex --name contract_review_key

All subsequent workflow artifacts will be encrypted with contract_review_key, ensuring that only authorized users with the matching key can decrypt the data, even if the local storage is compromised.

Enabling macOS Accessibility for Voice Commands

Voice‑driven automation requires the Accessibility API. Open System Settings → Privacy & Security → Accessibility and add /Applications/Purple.app to the list of allowed apps. Additionally, enable “Voice Control” under System Settings → Accessibility → Voice Control. Once activated, you can trigger Purple’s custom voice schema by saying “Hey Purple” followed by the command phrase.

Hands‑Free PDF Contract Review Workflow

Importing PDFs into Purple’s Workspace

Begin by placing the contract PDF in a dedicated Finder folder, e.g., ~/Documents/Contracts/Incoming. Then issue a voice command to Purple:

Hey Purple, import the latest PDF from Contracts Incoming.

Purple scans the folder, identifies the most recent file (based on creation timestamp), and loads it into its internal PDF engine. The engine creates a searchable text layer using OCR if the PDF is image‑based, guaranteeing that voice‑driven queries can reference any clause.

Summarizing Contract Obligations with Natural Language Prompts

After the PDF is loaded, request a high‑level summary:

Hey Purple, give me a bullet‑point summary of the payment terms and termination clauses.

Purple leverages its LLM backend to extract relevant sections, then returns a concise list in the macOS Notification Center and copies the text to the clipboard. You can immediately dictate a follow‑up command to expand any bullet:

Hey Purple, elaborate on the notice period for termination.

The AI responds with a paragraph‑level explanation, preserving the original clause numbering for reference.

Annotating Sections Using Voice Commands

To add a comment or highlight, simply point to the clause on screen (or say the clause number) and speak the annotation:

Hey Purple, highlight clause 7.2 and add a note: “Confirm renewal date with finance.”

Purple creates a visual highlight in the PDF viewer and attaches a text annotation stored in the encrypted vault. Multiple annotations can be chained in a single utterance, e.g., “Highlight 7.2, 9.1, and 12.4, and add respective notes.”

Exporting, Versioning, and Archiving the Reviewed Contract

When the review is complete, instruct Purple to finalize the document:

Hey Purple, export the annotated PDF to Contracts Reviewed with the filename “Acme‑2024‑Renewal‑Review.pdf”.

Purple saves a new PDF that embeds the highlights and notes, then creates a version entry in the ~/Documents/Contracts/Archive folder. It also logs the review session metadata—reviewer name, timestamp, and encryption key ID—into a secure JSON manifest that can be audited later.

Step‑by‑Step Terminal and Voice Command Guide

Launching Purple via Terminal for Scripted Automation

While voice commands are ideal for ad‑hoc reviews, batch processing of multiple contracts benefits from Terminal scripts. The following Bash snippet demonstrates how to loop through a directory of PDFs, summarize each, and store the results:

#!/usr/bin/env bash
INPUT_DIR=~/Documents/Contracts/Incoming
OUTPUT_DIR=~/Documents/Contracts/Summaries
mkdir -p "$OUTPUT_DIR"

for pdf in "$INPUT_DIR"/*.pdf; do
  echo "Processing $(basename "$pdf")..."
  # Ingest PDF
  purple pdf import --file "$pdf" --session "$(basename "$pdf" .pdf)"
  # Generate summary
  purple ai summarize \
    --session "$(basename "$pdf" .pdf)" \
    --topics "payment terms, termination, liability" \
    --output "$OUTPUT_DIR/$(basename "$pdf" .pdf)_summary.txt"
done

echo "All contracts summarized. Summaries located in $OUTPUT_DIR."

Save the script as summarize_contracts.sh, make it executable (chmod +x summarize_contracts.sh), and run it. Purple will process each PDF in the background, using the same BYOK key for encryption.

Creating Custom Siri Shortcuts for One‑Click Review

Open the Shortcuts app and add a new shortcut named “Review Contract”. Configure the following actions:

  1. Run Shell Script: purple pdf import --file "$HOME/Documents/Contracts/Incoming/$(ls -t $HOME/Documents/Contracts/Incoming/*.pdf | head -1)"
  2. Speak Text: “Contract imported. Awaiting your command.”
  3. Wait to Return: (None – allows you to speak to Purple directly)

Assign the shortcut to a keyboard gesture (e.g., ⌃⌥R) or expose it to Siri with the phrase “Hey Siri, start contract review”. This hybrid approach lets you launch the workflow with a single voice or keystroke, then continue hands‑free.

Sample Voice Script for End‑to‑End Review

The following script can be saved as a plain‑text file (review_script.txt) and fed to Purple’s voice interpreter:

Hey Purple, import the latest contract PDF.
Summarize payment terms, renewal dates, and confidentiality obligations.
Highlight clause 5.1 and add a note: “Verify discount schedule with procurement.”
Highlight clause 9.3 and add a note: “Check indemnity limits.”
Export the annotated PDF as “ClientX‑2024‑Review.pdf” to Contracts Reviewed.
Log the session and encrypt the notes with contract_review_key.

To execute, run:

purple voice run --script ~/Documents/Contracts/review_script.txt

Purple parses each line, performs the corresponding action, and provides audible confirmation after each step.

Frequently Asked Questions

Can Purple summarize a scanned (image‑only) PDF without manual OCR?

Yes. Purple automatically detects image‑only PDFs and runs its built‑in OCR engine before invoking the language model. The entire process is transparent to the user; you simply issue the summarization command, and Purple returns text extracted from the scanned pages.

How does BYOK protect my confidential contract data during voice processing?

When you import a PDF, Purple encrypts the raw file and any derived artifacts (highlights, notes, summaries) with the AES‑256 key you supplied via purple key import. The key never leaves your macOS keychain, and all decryption occurs locally. Even if an attacker gains filesystem access, the encrypted blobs remain unreadable without the BYOK key.

Is it possible to integrate Purple’s output with Microsoft Word for a formal executive brief?

Absolutely. After generating a summary, use the following voice command:

Hey Purple, draft a Word document titled “Acme Contract Executive Summary” using the latest PDF summary.

Purple creates a .docx file in ~/Documents/WordDrafts, preserving the bullet structure and inserting a header with the contract name and review date. You can then open the file in Microsoft Word for final formatting.
